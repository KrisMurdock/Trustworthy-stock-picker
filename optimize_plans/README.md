# optimize_plans 说明

`theories.md` 是按 13 个知识模块组织的炒股知识地图，同时作为选股、信号排序、风险控制、执行和策略回测的工程参考蓝图。它不构成收益承诺。

## 文档结构

- 总览：模块地图、三条阅读路径、模块依赖、编号与来源约定。
- 模块 01—13：每个模块包含模块定位、知识点、工程落地与验收清单、常见误区、与其他模块的关系。
- 附录 A：原 20 节、134 个小节到新模块的覆盖表。
- 附录 B：按来源反查知识点。
- 附录 C：原验收段到模块验收清单的映射。
- 附录 D：只作为研究假设、不进入生产默认值的表述。

## 维护约定

- 新知识点先归入一个主模块，其他模块只做交叉引用，不复制正文。
- 引用只写书名或来源名；网络来源写标题和链接；不编造页码或原书章节。
- 新验收项必须标注对应知识点编号，并写成可执行断言。
- 原书的固定点数、百分比、周期天数、杠杆和仓位示例，默认只作为研究假设或可配置参数。
- 旧版逐段摘编由 git 历史保留，不在正文复制两份。
