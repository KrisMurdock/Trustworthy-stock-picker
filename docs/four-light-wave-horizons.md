# 五日启动与20/40/60日波段延续

`four-light-study -wave-horizons` 增加独立 `wave_horizons` 报告及逐笔字段，并自动包含价格段、灯龄与行业报告。需要manifest v2和冻结分类。旧5/10日指标、四灯公式、信号分组与正式推荐不变；新模型 `upward_wave_horizons_v1` 是路径诊断，不增加长周期成功、回撤或买卖门槛。

## 两层评价

第一层保留原 `upward_wave_no_drawdown_v1` 五日启动状态。第二层从同一笔次日开盘模拟成交开始，独立观察20、40、60个冻结交易日，买入日为D1，不在回调低点重新锚定。

| 指标 | 口径 |
| --- | --- |
| 末端净标记 | DN收盘按原卖出滑点与费用估值，相对同一笔买入成本；不是已实现收益 |
| 净收盘峰值／回吐 | D1～DN净收盘最大值；峰值减末端净标记（百分点），全负路径峰值不强制归零 |
| 上涨比例／最长连涨 | D1与实际fill比较，D2起与前收比较；零不算涨且中断连涨 |
| 效率 | 末端相对fill的净价格变化／逐日价格变化绝对值之和，保留正负，全平为零 |
| D5后价格涨幅 | `(C[DN]/C[D5]-1)*100`，不是净收益之差 |
| D5后上涨比例／连涨 | 只用D6～DN，比例分母为N−5 |
| 创新高天数／最后创新高日 | 收盘严格高于此前最高收盘，以实际fill作为初始峰值；无创新高为0 |
| 最大浮亏／收盘回撤 | 继续描述，不否决成功、不作为筛选 |

整体涨幅可能主要来自前5日，因此D5后指标单独保留。startup_five为success/failed/unknown/not_entered的行，只是D5才可知的事后分层；不得当成信号日选股特征，也不能继续声称按原D1开盘可买到条件组。

## 完整性与分母

每个窗口只有known/unknown/not_entered，没有新的success标签。N个连续交易日都具备有效价格与原价格配对证据才known；缺日、停牌、变换变化、日历不足、观察截止或预留边界均保留unknown。D21异常不影响完整20日，D41异常不影响完整40日，更不能反向改变5/10日。

事件保存有效前缀 `days`，日期可追溯；窗口保存 `observed_days`，完整才有 `end_date` 和指标。只有46日的前缀不能用最后一日冒充60日；unknown指标明确为null，不混入均值。

每组、每窗口保留：

```text
selected = entered + not_entered + entry_unknown
entered = known + unknown
coverage = known / entered
effective_coverage = known / selected
```

首次／再次／未知段内组完整分解原首次全红；五日状态分层也完整分解各自全部信号，不因长窗口未知删掉样本。不同窗口的known集合不同，20/40/60均值不能直接相减当成同一队列的成长。

全期、逐日、逐月同时报告。比较只用startup_five=all：同日市场、同日同行业和再次相对段内首次。行业按每个完整N窗口计算，排除自身、至少5个其他有效窗口，按候选构成加权后日期等权。分别比较末端净标记、D5后价格收益及D5后上涨比例；前两者单位为百分点，后者为比例差。没有对事后启动组使用不匹配的行业基线。

长窗口高度重叠，本轮不给不适配60日窗口的10日块置信区间。描述性点差不是显著性、因果或独立验证。

## 运行与边界

```bash
four-light-study -manifest manifest.json -database all-market.frozen.db \
  -classification classification.json -classification-sha256 <冻结摘要> \
  -wave-horizons -events horizon-events.jsonl -timeout 1h > horizon-report.json
```

缺分类/摘要、旧manifest、取消、超时、来源或输出错误不得返回部分成功；events禁止覆盖，失败清理。数据库只读，观察价格不越过manifest边界。旧参数运行保持旧输出，原四份报告及事件去掉新增字段后逐字段相等。

原全市场开发信号仍为2026-04-08～08-11，价格止于08-19；不延长截止日来凑满60日，7月和8月不足长窗需报告覆盖。伊利股份8月20日至10月30日已在用户个案讨论中观察，只作为已选案例，不能再纳入“未污染独立留出”的声明。原软件没有提供该日信号证据，不能把用户指出的走势启动日写成商业软件买点。
