本轮没有找到同时满足“买入次日最高价净盈利触达率 ≥80%”与“单笔净亏损严格低于3%”的规则。9组预先定义的实验全部保留，8组有成交的规则均有亏损超限，历史风险证据规则没有入场样本。

- 买入模型仍是信号日后的交易日开盘；买入后的首个可卖出交易日为第1天，未止损/止盈则按该日收盘模拟退出。不能从日线声称精确持仓时长小于24小时。
- 2.5%和3%分别按最高价扣费及滑点是否触达计算，不要求收盘达标；分母为全部入场（包括未决），退出后价格和先后不明的触达不计成功。
- 亏损相对单笔买入总成本计算，等于3%沿用此前严格规则也不通过。最差单笔是实际退出模拟收益，不是账户最大回撤。

## 事实、缺点与下一轮方向

相对动量规则的两档次日成功率最高（45.14% / 40.47%），比次日基线高7.14 / 6.69个百分点，仍低于80%，且38笔亏损超限。它在各月的2.5%触达率为22.22%、62.26%、57.14%、40.91%、36.90%，没有一个月份达到80%，也未呈现稳定改善。该规则仅是当前对照中成功率最高，不能标为合格策略。

低波动规则将超限从基线51笔减少到2笔，但入场样本从379笔变为184笔，次日触达率降为5.43% / 2.72%。不能只对比亏损笔数就宣布有效：样本数和机会覆盖也同时降低，且2笔超限已违反硬条件。

基线51笔超限均发生在首个可卖出日开盘退出（stop_gap），其中27笔在买入日从开盘至收盘已跌至少3%，只有9笔在买入日至卖出日的隔夜开盘再跌至少3%。这两组可能重叠，其余样本可能由日内及隔夜较小跌幅和成本共同造成；“开盘止损”不能全部解释为隔夜大跳空。单纯把次日止损线收紧，无法逆转买入日已经发生、当日不能卖出的跌幅。

下一轮应先独立验证入场时点及持有期间风险：例如使用入场前已知的分钟数据设计尾盘入场，检验缩短买入日风险暴露能否改善亏损约束。尾盘价格、日内回撤或收盘信号必须来自当时已经结束的分钟，不得先看到全天收盘再假装提前成交；日线不能证明尾盘可成交。再检验入场前历史下行跳空、波动和市场状态的过滤。上述是待验证方向，本轮没有宣称它们有效。

基线12笔未决全部为除权窗口，仍保留在分母并阻止风险达标。当前历史股池选择偏差、样本缺口、重叠交易和日线先后不明也需要保留；用更多参数挑出少量高成功样本，不能替代冻结后的独立验证。
