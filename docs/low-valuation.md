# 全市场低估值观察

全市场低估值链路是一条独立的财务研究链路，用来从沪深 A 股全市场中找出“现价低于财务研究区间下沿”的股票，并把最接近估值区间的股票排在前面。它不是目标价、收益预测、成功概率或买卖建议，也不复用 A 股初筛、精排、成交模拟和推荐门槛。

## 链路

```text
sync-all 完整同步
  -> 读取 all-market.db 中每个有效股票的 as-of 不复权收盘价
  -> 新浪 jsvar.js 拉取 TTM EPS、前一年 EPS、每股净资产和总股本
  -> Tushare stock_basic 读取当前行业快照（可选）
  -> fairvalue.Calculate 生成 v1 财务研究区间
  -> 仅保留 close < lower 的股票
  -> 按 (lower - close) / lower 升序排名
  -> 保存到 all-market.db 的 recommendation 表，market=low_valuation
  -> run/once 读取快照并投递公众号文章
```

完整 `sync-all` 成功后，若 `low_valuation.enabled=true` 且没有使用 `-codes` 限制范围，会自动执行扫描并保存快照。也可以在全市场日线已同步后单独重跑：

```bash
stock-watcher scan-low-valuation [-as-of YYYY-MM-DD] [-workers 1..8] [-timeout 1h..72h]
```

自动链路失败不会回滚已经完成的全市场日线同步；运行日志和 `sync-all` JSON 的 `low_valuation_error` 字段会记录原因。修复上游或配置后可用 `scan-low-valuation` 重跑。

## 排名与价格口径

- 只接受 `trade_date` 等于信号日的收盘价；停牌、缺少当日 K 线或成交量为 0 的股票被过滤，不用旧价格补位。
- 全市场范围沿用 `all-market` 股票池，排除 ST、退市整理、北交所和 B 股；不是交易所全部证券。
- 价格使用 `daily_bar.adjust='none'` 的不复权收盘价，与 `fairvalue.Calculate` 的财务价格锚一致；前复权价格不参与估值。
- 估值不可用、财务请求失败、现价不低于区间下沿的股票不进入候选。
- 距下沿折价 `(lower - close) / lower × 100` 越小，排名越前；同分时按中枢空间降序、代码升序保证稳定。
- `fairvalue` 的公式、数据来源、异常过滤和置信度规则见[个股财务研究区间](fair-value.md)。低估值链路只增加全市场扫描、排序和文章，不修改公式。

## 数据保护

- 全市场没有当日有效不复权收盘价时，扫描返回错误，不生成空文章。
- 已定价股票不少于 100 只、但可用估值少于 50% 时，扫描返回错误且不保存快照；避免新浪整体故障时把“没有低估值股”当成真实结论。
- 单只股票财务失败只计入筛选分布，不补零、不补造区间。
- Tushare 行业快照只用于区分金融/非金融估值边界；行业缺失时按非金融边界计算，文章会展示行业覆盖率并提示风险。该快照是当前行业标签，不用于构造历史同业分位。

## 公众号文章

文章标题形如：

```text
全市场低估值股｜11月02日 财务折价观察
```

正文包含本期候选、财务研究区间、中枢、距下沿折价、中枢空间、TTM EPS、每股净资产、ROE、盈利同比、当前 PE/PB、筛选分布、数据覆盖率、方法边界和风险提示。没有候选时明确说明“本期没有股票满足条件”，不写成全市场看空，也不从区间内或区间上方递补。

投递使用独立路由 `low_valuation`，启用微信公众号草稿时默认进入 `wechat-draft`；投递目标日为信号日的下一交易日，09:30 后过期。相同信号日只保留一份稳定事件，重启不会重复发送。文章加载失败、过期或格式校验失败不会阻塞 A 股日报和港股通链路。

## 配置

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| STOCK_WATCHER_LOW_VALUATION_ENABLED | true | 是否在全市场完整同步后生成低估值快照 |
| STOCK_WATCHER_LOW_VALUATION_PUSH_ENABLED | true | 是否由 run/once 读取快照并投递公众号文章；依赖 enabled |
| STOCK_WATCHER_LOW_VALUATION_TOP_N | 20 | 文章最多展示的候选数，允许 1～50 |

## 已知限制

- 数据源是最近四季度财务快照，不是实时财报；披露滞后、周期峰值利润、一次性损益、商誉和会计口径变化都可能使区间失真。
- 新浪页面不提供财报公告日；该链路不宣称严格 point-in-time。v3 PIT 财务仍只用于研究命令，不进入本条链路。
- 全市场每只股票需要一次新浪财务请求，受 `market.request_interval` 限速影响，通常需要数十分钟；不能宣称实时或高频。
- 行业标签缺失时金融股可能按非金融边界计算。部署时应配置 `TUSHARE_TOKEN`，并检查文章中的行业覆盖率。
- 低估值不等于短期上涨，也不代表已经排除退市、停牌、审计意见或公司治理风险。
