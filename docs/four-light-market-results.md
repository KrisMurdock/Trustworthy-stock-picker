# 全市场四灯波段：首轮开发期结果

本轮已取消原排名与 Top N 限制，遍历冻结快照中的 5,027 只当前沪深股票。可评价子集中，首次全红的五日波段率为 **10.01%**，同日市场基准的逐笔汇总为 **10.89%**；按日期等权比较，首次全红相对同日基准为 **−1.23 个百分点**，描述区间跨零。当前证据不支持将首次全红或四灯同时转红升级为已验证买点。

本轮最主要的限制是**入场数据覆盖不足**：2,572 只股票的前复权与不复权数据来源不同，当前研究的同源要求将这些原价序列记为未知。来源不同不证明价格错误，但本轮没有完成异源配对验证。以下波段率只描述可评价子集，不能作为完整全市场的命中率。

## 数据与冻结范围

- 计算提交：`f49c6a4126e8e9716718c611defddd47c57041b3`；输出 `code_version=f49c6a4`，研究引擎 `four_light_market_wave_v1`。
- 四灯 `four_light_approx_v1` 与波段 `upward_wave_v0` 均未改公式或阈值；仍为近似、未对齐商业软件。
- 输入：SQLite 备份接口生成的一致副本，schema 1，读取后摘要未变化；没有迁移或写回生产库。
- 信号区间：2026-04-08～2026-08-11，共 86 个交易日；价格仅加载 2025-10-30～2026-08-19。
- 前复权为备份当前截面的历史窗口，没有逐日恢复当时可见的价格版本；也未消除后续行情修订影响。禁止读取预留日期的行情行，不等同于已经完成逐时点可见数据验证。
- 预留区间从 2026-08-20 开始，继续封存；输入截至日为 2026-10-30。沿用参考开发实验 `7a751e1a242a0fb9aca6a6b7a25eb523` 的日历与成交参数。
- 遍历 432,322 个股票日；当前灯色可判 427,394 个，缺当日行情 3,259 个，预热不足 1,669 个。全红事件 30,460 条，其中首次全红 17,689 条、持续全红 12,729 条、转换未知 42 条。
- 研究耗时 37.66 秒，峰值驻留内存约 27.2 MiB；全红逐笔路径以 JSONL 流式输出，未将全部路径保留在内存中。

基准包含事件组，日期等权增量是每个可配对信号日的“组内有效波段率 − 当日基准有效波段率”再平均，不能用表内两个逐笔汇总率直接相减替代。它也不是互斥控制组的因果效应。

首次全红的 17,689 条信号中：确认入场 6,661 条、明确未入场 1,182 条、入场未知 9,846 条；确认入场后又有 505 条五日路径未知。已确认入场范围内的有效覆盖为 92.42%，但有效样本只占全部首次全红信号的 **34.80%**。市场基准对应比例为 93.54% 和 **41.39%**。必须同时看两个覆盖口径，不能用前者掩盖未知入场。

首次全红的确认入场保守波段率为 9.25%，仅是已确认入场范围内的观察下界。五日平均期末净标记 −0.35%，平均从最高收盘净标记回吐 4.15 个百分点；这些是路径估值，不是实际卖出收益。

## 优化顺序

1. **先处理数据配对覆盖。** 2,570 只为腾讯前复权 / 新浪原价，2 只为腾讯前复权 / BaoStock 原价；同源腾讯对为 2,438 只，另 17 只在观察范围没有两套行情。优先取得同源成对窗口；若允许异源配对，先固定逐日价格、复权因子、日期与来源校验契约并独立版本化，再冻结新输入重跑开发期，不能为了提高波段率直接删去来源校验。
2. **补齐样本身份与行情背景。** 当前 5,027 只股票的上市日期字段均为空，历史 ST 和历史股池成员也未完整冻结；样本存在当前股池与存活者偏差。先补元数据，再检查月份、板块及市场状态中的失败是否集中。
3. **继续把首次全红作为主研究对象。** 保留持续全红、仅量能和价格灯参与分组。后续候选应检查信号出现时是否已上涨过久、是否追在放量末端；先固定候选规则和评价指标，再做开发对照。当前不支持提高“四灯同时转红”的权重。
4. 五日主指标、十日旁证和原预留边界继续冻结。覆盖和开发稳定性解决后，再单独开展预留区间检验；本轮未消费。
