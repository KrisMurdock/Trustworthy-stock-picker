# 实时 5 分钟预测 FeatureVersion 2 评估

本文记录 2026-10-21 在 `feat/predictor-calibration-v7` 上的离线实验。结论先写在前面：**FeatureVersion 2 没有改善下一根 5 分钟 bar 的点误差，校准方案又明显损害 high/low 包络覆盖率，因此不合并到生产主干，也不替换当前 `FeatureVersion=1` 模型。**

## 实验范围

- 任务：使用已完成 5 分钟 bar，预测同交易时段下一根 bar 的 high/low/close 相对当前收盘价收益。
- 股池：`config-diagnostic`，149 只当前配置股票；不是按历史时点可见的正式报告股池。
- 验证区间：2026-10-09 至 2026-10-20，共 8 个交易日。
- 样本：54,832 条，v1 和 v2 使用同一批样本、训练边界和评估指标。
- 训练：B0 expanding 基线，只使用验证日之前的数据；v2 增加市场上下文，但当前评估仍是 `config-diagnostic`，不能作为正式 point-in-time 验收。

## FeatureVersion 2 变更

相比 v1，v2 增加：

- 日内 MACD 线、MACD 柱、布林 %B 和带宽；日线 MACD 柱、布林 %B/带宽和 20 日成交量 z-score。
- 沪深 300 的 1/5/20 日收益、MA20 偏离、20 日波动率及上涨/下跌状态。
- 个股相对指数的 5/20 日相对收益、60 日滚动 Beta 和下行 Beta。
- 明确的缺失指示，市场上下文不可用时不伪造“平稳”状态。

v1 与 v2 使用相同的高/低/收目标和 GBDT 训练流程；v2 的 `FeatureVersion` 提升到 2，旧 v1 artifact 不再能由该分支加载。

## 结果

| 指标 | v1 | v2 | 变化 |
| --- | ---: | ---: | ---: |
| 三目标平均 MAE | 22.6957 bps | 22.7703 bps | +0.0746 bps（变差） |
| high MAE | 21.0415 bps | 21.2367 bps | +0.1953 bps |
| low MAE | 17.1352 bps | 17.1649 bps | +0.0296 bps |
| close MAE | 29.9103 bps | 29.9094 bps | -0.0010 bps |
| high/low 联合包络覆盖率 | 20.38% | 21.71% | +1.33 个百分点 |
| 预测区间平均宽度 | 52.3 bps | 53.6 bps | +1.3 bps |
| close 方向准确率 | 51.57% | 51.85% | +0.28 个百分点 |

按交易日配对比较，v2 相对 v1 的平均 MAE 差值为 `+0.0746 bps`，95% 日块 bootstrap 区间为 `[-0.0048, +0.1639]`；8 天中只有 2 天改善。区间和方向只有轻微变化，且 close 方向准确率仍低于多数类基线 `52.87%`。这不足以支持“v2 提升了实时预测性能”的结论。

## 校准诊断

在 16 个交易日的诊断样本上，尝试对 B0 输出做固定比例缩放：

| 方案 | 平均 MAE | high/low 包络覆盖率 | 区间平均宽度 |
| --- | ---: | ---: | ---: |
| 原始 B0 | 19.7977 bps | 23.04% | 47.0 bps |
| high/low × 0.85，close × 0.25 | 19.5405 bps | 14.38% | 40.0 bps |
| 仅 close × 0.25 | 19.7635 bps | 23.04% | 47.0 bps |

`0.85/0.85/0.25` 方案只把平均 MAE 改善 `0.2571 bps`，却把 high/low 联合覆盖从 23.04% 降到 14.38%，属于用区间实用性换取很小的点误差收益，已否决。仅校准 close 的收益不足 `0.04 bps`，同样不值得引入。预测校准仍保留为评估能力，生产 artifact 默认不启用。

## 结论与后续

- **不合并到 `main`**：本轮没有可复现的点误差改善，且校准损害包络覆盖率。
- **不替换生产模型**：当前生产仍是 `FeatureVersion=1`；v2 artifact 不兼容，不能直接部署。
- 下一轮优先补正式 point-in-time 股池、盘中指数分钟数据、可追溯的行业/板块归属和更长样本外窗口。
- 区间任务应单独研究分位数或目标区间模型，不能用缩小点预测来冒充可靠区间；同时报告覆盖率和宽度，而不只报告 MAE。
- 评估命令、逐日指标和负结果应保留，避免后续重复尝试同一组无收益特征。

复现入口：

```bash
go run ./cmd/stock-watcher predictor-eval \
  -universe config-diagnostic -max-stocks 149 -max-training-days 120 \
  -as-of 2026-10-20 -baseline-only -validation-days 8 \
  -dump-predictions .scratch/v7/eval/v2-8d.jsonl
```

该命令只读行情和上下文数据库，不训练生产模型、不写预测库、不发送飞书。`config-diagnostic` 结果不是正式样本外验收。
