# RSI、MACD 与布林线：固定规则对照结果

本轮完成8组实验，**没有符合全部目标的策略**。观察到的最高联合成功率是MACD组的10%，但它仍有单笔亏损超限。RSI组没有出现已完成交易超限，联合成功率为9.09%，买入日正浮盈率仅54.55%，也未通过要求。没有根据这一轮结果继续调阈值，没有发布股票推荐。

## 输入、规则与边界

运行版本 `ec6965b3b174c0b6714f4a00f874b6713a8dd57a`，引擎 `indicator_selection_v6`。复用父实验 `60829ac792a428c4009bda069b525c5b` 的完整冻结快照 `fedf815af55dcd229be02034509218e2c9ffa68628317cd7f115634848601e8e`，不重读同步后的行情。

信号区间为2026-09-18至10-08，共9个信号日、58/104支股票、522条股票/信号日候选。10-13至10-15没有计算交易结果。所用开发日期在前几轮已被查看，不是独立样本；实际入场的日期更少，仅3～9天，全部组均不足30笔完成、10个入场信号日的最低门槛。

所有组保持同一机会排序、Top5、分钟入场价区间/反弹、费用和次日退出模型，只改变前一日选股过滤。参数在运行结果之前固定，详细口径与命令见[实验说明](experiments.md#rsi-macd-与布林线对照)。新基线逐笔成交与旧版本完全一致；旧档案payload摘要前后一致。

## 实验方向、发现的缺点与下一步

| 方向 | 本轮证据 | 后续应验证的问题 |
| --- | --- | --- |
| RSI回升过滤 | 原基线12笔中移除3笔、增加2笔；避开原−9.461%超限，原来唯一的联合成功保留，但没有新增联合成功，比例上升主要来自分母减少 | 固定该门槛后观察新日期；风险减少是否稳定，买入日负浮盈为何仍有5笔 |
| MACD增强过滤 | 唯一联合成功仍是原来的1笔；从12笔变10笔得到10%，仍保留原大额超限 | 增强动量是否经常出现在高波动、高位置的股票，不能把柱增强当作风控 |
| 布林线修复 | 71/522候选通过；两笔实际净止盈交易的买入日浮盈分别约−2.131%、−1.094%，因此联合成功均失败 | 仅凭较低带内位置加回升是否仍过早入场，需用新数据验证日内确认而非事后剔除亏损 |
| 两项共振 | 13笔入场，联合成功仍1笔；新增5笔入场没有新增联合成功 | RSI与MACD可能提供重复信息，多项满足是否只改变样本而未改善目标 |
| 三项共振 | 15/522候选通过，仅4笔入场，且丢失原来唯一联合成功 | 过度收紧是否损失机会；不能用少数交易或空仓证明安全 |
| 波动量能约束 | 移除原超限样本后新增另一笔−3.244%亏损；该笔买入日浮盈已约−3.016% | 日线低波动仍挡不住买入后的下跌，应单独检验入场时点与当日价格路径 |
| 两项共振加约束 | 仅5笔入场，正浮盈1笔，联合成功0；平均亏损较小但仍为负 | 平均亏损缩小是否只是删掉交易，不能抵消成功率和覆盖下降 |

下一轮优先围绕“买入日收盘正浮盈”设计可实时判断的入场确认，例如反弹之后是否站稳当日均价或更长分钟趋势；应先固定可观察条件，再做单变量对照，不能用最终收盘判断是否买入。该方向尚未实现或验证。RSI组可保留为风险变化的观察对照，不能作为已验证推荐规则。继续累积分钟历史后，才有条件测试未查看区间的稳定性。
