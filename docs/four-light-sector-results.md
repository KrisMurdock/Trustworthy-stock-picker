# 四灯行业对照结果：2026-11-02

本轮在5,027只股票的原开发区间增加官方历史行业分类及同日同行业基准。**7月确有明显行业分化，但首次全红在同行业内仍然落后；简单要求个股或行业过去20日更强，没有稳定解决7～8月问题。下一步重点应转向四灯触发时点及此前价格路径，暂不增加行业强弱硬门槛。**

## 数据与方法

- 代码：`6acafe10b559fb035d6f0ad4eabb440ccfff64a9`；上下文策略：`published_sector_relative20_v1`；输入与公式、成交模拟、波段目标沿用上一轮。
- 信号2026-04-08～2026-08-11，86个交易日；价格最多读取到2026-08-19，2026-08-20起预留区间未消费。
- 分类来自中国上市公司协会[2025年下半年行业分类官方文章数据](https://www.capco.org.cn/dataFile/zsxfb/hyfl/hyfljg/d9221cd5eb1448e5956f0e9d84ecba89.js)及[股票代码排序PDF](https://sp.capco.org.cn:82/file/202604/hangyefenlei/2025xiaban/2025xiabangupiaodaima.pdf)，官方发布日期2026-04-03，早于开发起点。
- 使用门类加大类，例如C39、I65、J66。PDF共5,463个代码，两种独立转录方式核对代码、简称和大类一致；冻结股池覆盖4,955/5,027=98.57%，72只无分类。
- `snapshot_as_of=2025-12-31` 仅由“2025年下半年”标题解释为报告期末，原文没有给出逐股生效日。固定使用这一旧版分类，不宣称每天行业归属均正确；此次下载也不是4月本地留存的原始版本。
- 两个条件分别为个股过去20日涨幅高于同行业、同行业过去20日涨幅高于市场；使用信号日及之前连续21个交易日，排除自身，至少5只其他有效参照，不按未来结果选参照。不叠加量比或两个条件。
- 同行业未来波段基准按候选当日行业构成加权，逐笔排除自身，然后日期等权；至少5个其他已知波段窗口。未知与不足参照单列，不补零。完整契约见[同行业对照](four-light-sector-context.md)。

四灯仍为近似、未对齐商业软件的 `four_light_approx_v1`。波段仍为 `upward_wave_no_drawdown_v1`，没有新增回撤否决；未来波段率是事后标签，不是实际组合收益。

## 下一步优化方向

1. **保留行业作为环境信息和对照基准，优先研究触发时点。** 下一轮可先冻结“价格三灯此前连续红了多久”和“首次全红前的价格路径”两个描述，再评价等待量能补红是否过晚，以及回调中的反抽和新波段启动是否混在一起。只用信号日及之前的数据定义阶段，先描述，不直接堆过滤阈值。
2. **把买入后的启动与持续作为主问题。** 先前有效失败中，启动/连续性不足合计86.25%；本轮行业控制后7月差距仍存在。7月仅量能补红组为42/516=8.14%，价格灯参与转红组为173/1,357=12.75%；但全期两组分别22.89%和22.31%，方向并不稳定，不能直接删掉量能补红或宣称价格灯参与必然更好。
3. **适度放量继续作为研究参考，不合并新条件。** 同时看全期、各月、同日同行业及覆盖率。继续不设回撤阈值，保留描述；四灯公式冻结，预留区间继续封存。需要独立时期或前瞻记录后，再讨论正式选股接入。
