# 低估值低套牢观察

“低估值且低套牢”是全市场低估值链路的独立交集观察。股票必须同时满足：

1. 信号日不复权收盘价低于财务研究区间下沿；
2. 套牢 V3 信号有效，状态不是 `unknown`；
3. 上方套牢量不超过 `value_trapped.max_trapped_ratio`，默认 30%；
4. 不复权历史至少 250 个交易日，信号日有成交，20 日估算成交额不低于 2,000 万元。

它不是买卖建议，也不进入股池初筛、精排、正式推荐或成交模拟。交集为空时文章明确说明，不从低估值或低套牢任意一边递补。

## 链路

```text
sync-all 完整同步
  -> lowvaluation 扫描全部 close < lower 的候选
  -> 保存 low_valuation 快照（保持原 Top N）
  -> 仅对全部低估值候选运行 trappedscan
  -> strategy.AnalyzeTrappedSignalV3（turnover_adjusted_v3）
  -> 剔除 unknown、历史不足、信号日无成交、低流动性和套牢量超过上限
  -> 按“距下沿折价、套牢量、20 日成交额、代码”排序
  -> 保存到 all-market.db 的 recommendation 表，market=value_trapped
  -> run/once 读取快照并投递《低估值且低套牢》公众号稿
```

完整 `sync-all` 成功后，只有低估值扫描通过覆盖率保护，才会继续生成交集快照。低估值失败时不保存 `value_trapped`；套牢扫描失败时保留已经保存的低估值快照，但本次不生成交集。日线已同步后可单独重跑：

```bash
stock-watcher scan-value-trapped [-as-of YYYY-MM-DD] [-workers 1..8] [-timeout 1h..72h]
```

## 数据口径

- 低估值侧和套牢侧使用同一个 `all-market.db` 信号日，价格均为不复权收盘价。前复权只用于其他形态研究，不用于财务估值或历史成本。
- 低估值侧使用新浪 TTM EPS、前一年 EPS、每股净资产、四季度净利润和总股本生成保守下沿、中枢与上沿；完整公式见[个股财务研究区间](fair-value.md)。
- 套牢侧使用最近 120 个交易日不复权 OHLCV。成交量先按来源换算为股数，再用低-收-高三角分布展开；历史筹码按“昨日剩余筹码 × (1 - 当日换手率) + 当日新增成交”逐日衰减，信号日新增筹码不参与当日衰减。
- 换手率来自搜狐日度指标，只为低估值候选抓取，不重复扫描全市场。零成交日保留为未换手样本。
- 以成交股数和换手率反推的流通股本变化超过阈值时，信号记 `unknown` 并剔除；该检查只是代理口径，不能替代正式除权、送转和股本事件数据。
- 三档套牢区按现价上方距离划分：浅度 0～5%、中度 5～15%、深度 15% 以上。文章展示每档实际成交价区间和归一化后的份额，并给出加权成本所在档位作为“当前套牢区”。

## 排名与保存

排序依次为：

1. 距区间下沿折价 `(lower - close) / lower` 升序；
2. 上方套牢量升序；
3. 20 日估算成交额降序；
4. 代码升序。

系统不计算综合分，避免把百分比折价和套牢量混成不可解释的分数。快照默认最多保存前 20 只，`recommendation.market='value_trapped'`，事件 ID 为 `"<推荐ID>:value_trapped"`。

## 公众号文章

标题形如：

```text
低估值且低套牢｜11月03日 双重观察
```

正文包含全市场覆盖数、低于区间下沿数量、套牢有效数量和最终交集数量；每只股票展示：

- 现价、行业和 20 日平均成交额；
- 财务研究区间下沿/上沿、中枢和距下沿折价；
- 套牢状态、上方套牢量、当前套牢区和主要筹码档位；
- 浅度、中度、深度三档价格区间及各自份额。

文章同时展示筛选分布、套牢 `unknown` 原因、方法和风险边界。没有交集时明确说明“没有股票同时满足”，不写成市场判断。

投递使用独立路由 `value_trapped`，启用微信公众号草稿时进入 `wechat-draft`；目标观察日为信号日的下一交易日，09:30 后过期。相同信号日重复运行或重启不会重复入队。快照缺失、加载失败、格式校验失败或过期只跳过本路由，不影响日报、港股通和低估值投递。

## 配置

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| STOCK_WATCHER_VALUE_TRAPPED_ENABLED | true | 是否在低估值扫描成功后生成交集快照；依赖 `low_valuation.enabled` |
| STOCK_WATCHER_VALUE_TRAPPED_PUSH_ENABLED | true | 是否由 `run`/`once` 读取快照并投递公众号文章；依赖 `value_trapped.enabled` |
| STOCK_WATCHER_VALUE_TRAPPED_TOP_N | 20 | 交集文章最多展示的候选数，允许 1～50 |
| STOCK_WATCHER_VALUE_TRAPPED_MAX_TRAPPED_RATIO | 0.30 | 最大上方套牢量比例，允许 0.05～1 |

250 个交易日最低历史和 2,000 万元最低 20 日成交额当前固定为研究门槛，不提供环境变量。

## 已知限制

- 套牢量是成交筹码估算，不是券商持仓或真实成本；成交量无法区分买卖方向、机构/个人或锁仓筹码。
- 换手率缺失、股本口径变化、停牌与零成交会使部分股票进入 `unknown` 或被剔除，不能把剩余样本当成全市场完整分布。
- 低估值区间是财务相对估值，不是目标价；周期利润高点、一次性损益、商誉和会计口径变化都可能使区间失真。
- 交集只降低两类单边条件造成的噪声，不代表上涨概率、收益承诺或交易建议。
