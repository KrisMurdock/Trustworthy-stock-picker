# 缠论结构门控与本地周期选择

本文件记录 `waditu/czsc` 结构思想的 Go 化落地、当前生产门控和实验边界。实现不依赖 Python、Rust 子进程或外部服务。

## 上游理解

对照仓库为 `waditu/czsc`（`v1.0.2`，commit `5d350a943d6b1935561765fed5467c234973d121`）。只参考算法行为，不复制源码；仓库根的 Apache-2.0 声明与 Rust workspace 的 MIT 声明并不一致。

上游主路线是：原始 K 线做包含合并，识别严格顶/底分型，按交替分型构造笔，再由重叠笔构造中枢。上游没有现成的 5/15/20 分钟共振规则，也没有可直接复用的 A 股分钟边界契约；本项目从已保存的完成 5 分钟线派生其他周期，收盘边界固定为 `15:00`。

## 本地周期

生产契约使用 **日线 / 30 分钟 / 5 分钟**。15 分钟只保留诊断用途，不参与正式门控；20 分钟没有本地数据优势，不采用。原因是本地分钟历史短于日线，且 5 分钟是唯一原生落库周期：

| 周期 | 最低完成根数 | 本地数据约束 |
| --- | ---: | --- |
| 日线 | 240 | 默认 365 个自然日的分析窗口实际只有约 240 个交易日 |
| 30m | 96 | 存储单次最多 640 根原生 5m，可派生约 13 个完整交易日、约 104 根 30m |
| 5m | 240 | 约 5 个完整交易日即可满足 |

数据不足、错日、错源、复权不一致、信号日路径不完整或 30m/5m 不是同一快照时，门控落 `unknown`，不会当成通过。分钟数据由存储层一次读取原生 5m 后派生，写入层不允许保存派生周期。

## 价格口径

- 日线结构使用前复权 `qfq` 分析序列。
- 30m/5m 使用不复权序列，和成交模拟保持一致。
- 跨口径比较按信号日 `factor = qfqClose / rawClose` 把分钟价换算到 qfq 尺度。
- 换算因子异常、信号日日期不一致或序列缺失时，结构门控和实验回抽状态机都拒绝通过。

## 结构规则

实现位于 `internal/chanlun`，规则固定且可复现：

- 包含关系逐根处理，方向由前两根合并 K 线决定；相等高低点有固定 tie-break。
- 分型要求三根合并 K 线的高、低点严格成立；连续同类分型保留更极端者。
- 笔固定最少 6 根合并 K 线；首个候选无效时继续向后扫描，不终止整个序列。
- 最后一笔在出现后续反向笔前保持 provisional，不参与区间和方向判断。
- `stroke_zone` 是连续三个完成笔的公共交集，`ZD = max(low)`、`ZG = min(high)`；没有公共交集就不发布。报告中写“笔重叠区”，不冒充严格缠论中枢。

## 生产门控

`structure_guard.mode` 默认为 `shadow`：

- `shadow`：记录日线结构、30m/5m 否决证据、`observation_rank` 和 `eligible_rank`，但正式推荐仍走旧门控。
- `enforce`：正式 Top N 只能来自 `guard_status=pass` 的 `eligible_rank`；没有合格股票时输出空推荐，不从全池递补。

日线决定方向：

| 状态 | 条件 |
| --- | --- |
| `pass` | 有有效笔重叠区且收盘不低于 `ZD`；或没有区间但最近完成笔向上且收盘站上最近底分型高点 |
| `fail` | 收盘跌破最近区间 `ZD`；或最近两个区间中轴下移且收盘低于最新中轴 |
| `unknown` | 日线不足 240 根、没有完成笔，或没有可验证的向上结构 |

30m/5m 只有否决权，不能单独产生 `pass`：

- 30m 收盘（换算后）跌破日线 `ZD`：否决。
- 5m 收盘跌破 30m 最近完成底分型低点：否决。
- 低级别没有足够分型、笔或区间：只记 `unknown`，不额外解释成买点。

报告 schema 3 新增 `structure_guard`、`guard_passed`、`observation_rank`、`eligible_rank` 和可复现评分推导。旧 schema 1/2 报告保持只读兼容。`structure_guard=pass` 只表示“未被结构过滤”，不是第一、二、三类买点，也不能绕过历史证据、机会分、风险和留出验证。

日线报告的 `Eligible` 仍表示有效日线覆盖率，不因结构门控缩小；主卡表格先给出 Top10 的状态、价格和主要风险，详情卡逐只补齐以下证据：

- `结构门控`：日线 pass/fail/unknown、30m/5m 否决原因、观测排名和可入选排名。
- `缠论门控`：旧 5/15/30 路径的通过、未通过或未知原因，仅用于影子期对照。
- `评分推导`：基础分、日线评分贡献、加减分项、机会分和历史证据融合的完整算式。
- `规则`：当日匹配的固定日线规则。

## 实验回抽状态机

`strategy.EvaluateReboundSignal` 是独立实验原语，状态为 `watch/armed/confirmed/failed/expired`：

- 日线门控通过后，30m 回抽低点进入日线 `[ZD,ZG]` 且收盘不低于 `ZD` 才进入 `armed`。
- `armed` 后最多 6 根 5m 内，若出现底分型且收盘站上其高点，进入 `confirmed`。
- 5m 收盘跌破 `armed` 回抽低点，或 30m 收盘跌破 `ZD`，进入 `failed`。
- 6 根 5m 内未确认且未失效，进入 `expired`。

所有判断只使用完成 K 线，并显式应用信号日复权换算。该状态机不接管正式推荐，也尚未接入 `experiment` 的逐笔报告和回放；当前只作为策略包内实验原语，接入前必须补齐快照冻结、逐笔证据和独立样本设计。它不得表述为第一、二、三类买点。

## 验证与限制

- 2026-10-16 的本地副本约有 104 只股票、14 个完整分钟交易日；这只能验证结构正确性和数据覆盖，不能证明收益有效性。
- 旧 5/15/30 实现曾在北方稀土、中国稀土等样本上出现大量分型但零完成笔；修复笔扫描后 30m 结构可得性改善，但仍受分钟历史长度限制。
- 影子期至少需要 5 个交易日，记录日线 240 根、30m 96 根、5m 240 根的覆盖，`unknown` 比例，新旧 `passed/selected` 差异和稳定原因代码，再决定是否切到 `enforce`。
- 在独立分钟历史、复权事件和样本外验证充分前，不宣称“缠论选股已验证”，也不把影子期通过比例解释成未来胜率。

验证命令：

```bash
GOFLAGS=-p=1 go test -count=1 ./...
GOFLAGS=-p=1 make test
make smoke
make dashboard-smoke
```

真实数据只读核对使用 `preview -as-of <日期>`，不得同时启动第二个写进程或连接真实飞书作为测试依赖。
