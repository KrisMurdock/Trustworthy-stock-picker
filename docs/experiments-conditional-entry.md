# 条件低吸与指定区间：首轮记录

截至2026-10-15，本地固定程序已经支持「选择信号日期区间 → 前一日选股 → 到价反弹入场 → 买入日浮盈验收 → 次日退出/触达统计 → 实验归档」。这轮验证程序的计算与复现能力，固定规则没有通过策略目标；未据结果调整阈值，也未产生买入推荐。

## 固定输入与执行

代码版本：`133497cd67681a3585c0250895eb9d1d92a6e44a`，引擎 `conditional_entry_v5`。
快照：`fedf815af55dcd229be02034509218e2c9ffa68628317cd7f115634848601e8e`，截止2026-10-15。104支股池中58支有配对日线及分钟路径；5分钟覆盖2026-09-18至10-15，其中09-18不完整，后续13个交易日完整。不是十年分钟回测，也不是全股池结论。

固定规则见[实验说明](experiments.md)：每日先按信号特征取前5名；预设收盘下方0.5%～2%的区间，已完成5分钟线从当时可见低点反弹至少0.3%，下一根开盘加滑点仍在区间才买；最迟14:30，先跌破区间或首次触发后跳出则放弃。止盈目标净3%，最晚在买入次日退出。没有用全天最低价或最终收盘正负决定是否买入。

## 结果与失败证据

9个信号日共45条候选记录；12笔入场且完成，33次未入场，无缺失分钟路径或未决交易。

| 指标 | 本轮结果 |
| --- | --- |
| 买入日扣成本浮盈为正 | 7 / 12，58.33% |
| 买入日不为正 | 5 / 12，41.67% |
| 次日净触达2.5% / 3% | 均为1 / 12，8.33% |
| 买入日为正且次日净触达2.5% / 3% | 均为1 / 12，8.33% |
| 净亏损达到或超过3% | 1笔 |
| 最差单笔净收益 | -9.461% |
| 已完成交易平均净收益 | -1.470% |
| 结论 | 风险不达标；买入日条件及80%目标未达到，样本量也不足 |

33次未入场包括：未反弹触发12次、首次触发后价格出区间10次、先跌破区间10次、成本与风险预算不足1次。未入场不算成功；程序不会根据之后盈利补选股票。

超限样本为 `2026-09-24/sz002669`：09-28 09:35模拟以14.95元入场，买入日收盘14.76元，扣成本浮盈-1.440%；09-29止损跳价退出13.55元，最终净亏损9.461%。它既违反买入日正浮盈条件，也违反单笔亏损限制，不能通过事后删除该股票改善统计。

## 下一步与验证边界

下一轮可预先设计“信号日波动与过度偏离均线限制”，检验是否能减少买入后继续下跌；或独立检验更晚确认反弹是否减少买入日负浮盈，同时记录因确认较晚错过收益的代价。这些是假设，尚未证明有效，不应针对这一笔亏损反复调参。

默认试验保留10-13至10-15三个分钟交易日，剔除退出日触碰边界的交易。本轮显式区间恰好使用相同开发日期，但本身不声明独立留出集。09-18至10-08与[上一轮日线实验](experiments-next-day.md)当时的留出期重叠；本轮查看后，这段日期不能再作为旧策略未见的验证样本。旧档案保留当时结论，后续最终验证须重新冻结未查看的数据。

短分钟历史、当前股池选择偏差、同根5分钟线内成交顺序及模拟滑点仍限制结论。触价不等于保证成交，历史门槛不能承诺未来收盘为正或实盘亏损绝不超限。

本地验证通过，部署后未验证。验证包含全量竞态、静态检查、原生命令和真实浏览器、容器构建与浏览器，以及真实CIFS档案只读预览。当前运行服务未更新，合并及部署后才能在原服务看到新增组件。
