# 买入后上涨波段评价

**当前全市场研究使用 `upward_wave_no_drawdown_v1`**：买入后 D1/D2 启动，未来五日内出现上涨较连续、末端扣费涨幅达到信号日 1 倍 ATR14 百分比的片段。盘中先跌和收盘回撤仅描述，不设成功否决阈值；十日单列。manifest v2 显式选择该模型及新的价格配对策略，见 [全市场研究契约](four-light-study.md)。

旧排名实验、旧 manifest v1 与历史档案继续使用 `upward_wave_v0`，下面保留其冻结定义以供重放。`upward_wave_v0` 评价的是：**按既定规则买入后，未来几天是否尽早出现上涨较连续、回撤较浅的一段行情。** 五日为主窗口，十日单列为旁证。它是事后路径标签，不是新的买入指标、择时卖点或收益承诺。

四灯仍使用 `four_light_approx_v1`，保持 `approximation=true`、`alignment_status=unverified`。本次只改变研究评价，不修改四灯公式、机会分、每日推荐、全市场归档或通知。

## 入场与时间轴

- T 日收盘后生成信号，沿用下一交易日开盘的成交、跳空、预算、费用和滑点规则。采用逐笔 `outcome.entry_day` 中已经模拟出的成交价、股数、买入成本。
- 买入日为 D1。主窗口为 D1～D5，旁证为 D1～D10。这里的五日包含买入日，与旧模型“买入后最多五个可卖出交易日”不同。
- D1 上涨以收盘价高于实际模拟成交价为准，D2 起以收盘价高于前一交易日收盘价为准。平盘不算上涨，也中断连涨/连跌。
- 连续交易日依据快照中冻结的交易日历。不能用“下一条有行情的记录”跨过缺失或停牌交易日。
- 旧交易模型即使已经止盈或止损，波段观察仍延续至完整窗口。窗口净标记与实际交易盈亏分开保存。

默认开发实验保留原有开发/预留分界。标签在读取价格和复权因子之前检查边界，不读取预留区间；五日完整、十日跨界时分别记已知和 `unknown`。显式 `-from/-through` 只限制信号日，不自动声明保留集，观察可以延伸至该信号区间之后、快照截止之前。

## v0 成功条件

在每个完整窗口内寻找连续的日期片段，以下条件必须同时满足：

| 项目 | 冻结定义 |
| --- | --- |
| 开始 | D1 或 D2，且该日必须上涨，不能把等到 D3 才上涨的行情算作及时启动 |
| 上涨次数 | 至少 3 个上涨日 |
| 上涨密度 | 上涨日 / 片段交易日数 ≥ 75% |
| 连续性 | 至少连续上涨 2 日 |
| 幅度 | 片段末收盘扣费净标记，相对实际买入成本 ≥ 信号日 ATR14 百分比的 1 倍 |
| 先跌风险 | 从入场至片段末，最低价扣费净标记的最大亏损 ≤ 0.5 倍 ATR14 百分比 |
| 收盘回撤 | 从入场至片段末，历史收盘峰值至后续收盘的最大跌幅 ≤ 0.5 倍 ATR14 百分比；入场价也作为初始峰值 |

ATR14 沿用仓库特征：最近 14 根完整日线的真实波幅 TR 简单平均，再除以信号日收盘价；不是 Wilder 递推平滑。只取 T 日已知的前复权特征，不随未来窗口重算。上述参数是研究起点，尚未独立验证或调优。

多个片段达标时固定取**最早结束的片段，同一结束日取较早开始的片段**。不事后选择利润最大的片段，也不将买入价重置为后来出现的低点。幅度与先跌风险始终从实际入场计算；开始于 D2 的片段也必须承担 D1 的风险。

旧手续费模型继续计算双边佣金、最低佣金、过户费、卖出印花税和滑点，收盘/最低价标记使用卖出滑点与价格向下取整。它们是假设扣除卖出成本后的估值，不假定当天能实际卖出；D1 的 T+1 限制和后续跌停不可卖出均不能被这些净标记绕过。最大盘中净浮亏保守使用每日最低价，无法从日线重建日内顺序。收盘最大回撤使用价格路径，不能当作日内峰谷回撤或账户回撤。

## 无回撤门槛版本

`upward_wave_no_drawdown_v1` 保留 v0 的开始、上涨次数、上涨密度、连续性和幅度五项条件，取消表中“先跌风险”和“收盘回撤”两项门槛。仍固定选择最早完成的合格片段；启动于 D2 时，风险描述仍包含入场以来的 D1，不能重置成本。

新模型采用 `causal_affine_ohlc_v1` 校验 qfq 与原价关系：仅用信号日及以前的近期成对 OHLC 建立固定映射，后续逐日验证。允许稳定的加减、比例或正斜率仿射关系，不再将收盘价比值漂移直接认作公司行为；数值关系改变、舍入外推不兼容等均是 `price_transform_changed` 未知。配对证据不足、成交股数不一致也单列未知。此版本不实现分红、送转的持仓现金流，不能将数值一致性称为不存在公司行为的证明。

模型与配对规则均参与版本标识；聚合器拒绝混合两个模型，旧档案不回写。两种模型的波段率不能直接作为优化增量；量比候选必须与同一个新模型下的首次全红及市场基准比较。

## 同时保留的连续指标

每笔保存逐日日期、收盘价、涨跌、收盘净标记和最低价净标记，并独立保存两个窗口：

- 达标片段：启动日、结束日、段长、上涨比例、最长连涨/连跌、效率、末端净标记、入场以来最大浮亏和收盘回撤。
- 完整窗口：同样的连续性和风险指标、期末净标记、最高收盘净标记、回吐百分点。即使早期有成功波段，后续下跌仍完整记录。
- 效率 = `(片段末收盘 − 片段起始参照价格) / Σ|相邻价格变化|`。D1 的起始参照为成交价，D2 为 D1 收盘价；范围为 −1～1，全平为 0。下跌不能取绝对值后伪装为高效上涨。
- 回吐 = `窗口最高收盘净标记 − 窗口末收盘净标记`，单位是百分点；最高点只比较实际收盘，不能看成已实现收益。

例如先连续涨三日、随后跌回买入价下方，仍可能有“出现有效波段”的标签，同时显示负的期末净标记和较大回吐。单日冲高、深跌后反弹、到 D3 才启动均不能仅凭期末赚钱算成功。

## 分母、缺失与汇总

每个窗口独立统计以下漏斗，空分母输出 JSON `null`，网页显示不可计算：

```text
预选 = 确认入场 + 明确未入场 + 入场未知
确认入场 = 有效路径 + 路径未知
有效路径 = 波段成功 + 波段失败
有效样本波段率 = 波段成功 / 有效路径
有效覆盖率 = 有效路径 / 确认入场
保守波段率 = 波段成功 / 确认入场
```

保守率仅是**已确认入场样本范围内**的观察下界，不能涵盖入场未知，更不能当未来成功概率。明确未入场包括跳空/成交约束、预算不足、成本占满原风险额度；缺入场证据不当作明确未入场。已确认入场后缺数、停牌、无效 K 线、ATR 不可用、日历不足、快照未来不完整、跨预留边界或复权因子变化都单列原因。

整个窗口必须完整才判成功/失败；已观察到早期达标段但后半段缺失时仍为 `unknown`，避免仅报告有利前缀。五日与十日各自核对：D6 出现公司行为不会反向污染完整 D1～D5 的标签。复权因子变化沿用旧研究 0.2% 容差，不能声称识别所有微小公司行为；尚未实现分红拆股现金流核算。

汇总的平均启动日、段长、片段效率只统计成功片段；平均期末净标记、回吐和最大浮亏统计全部有效窗口，不只统计成功样本。报告同时保留独立信号日数；同日多股票和相邻日期信号相关，不能把逐笔数量当独立试验次数。

## 运行与查阅

实验引擎升级至 `indicator_selection_v8`，存储仍是 schema 1 的可选 JSON 扩展。新开盘基线、上影线/风险过滤和四灯实验会记录 `upward_wave_v0`；次日退出和分钟条件入场不自动混用该定义。历史档案保持原样，没有新字段即“未计算”，需要在同一冻结快照重跑。

```bash
# 使用旧记录的不可变输入，重新建立当前代码版本的基线
./bin/stock-watcher experiment -parent <旧记录ID> -policy baseline

# 用刚生成的新基线分别比较，保持日期区间和构建一致
./bin/stock-watcher experiment -parent <新基线ID> -policy four-light-all-red
./bin/stock-watcher experiment -parent <新基线ID> -policy four-light-flip-any
./bin/stock-watcher experiment -parent <新基线ID> -policy four-light-flip-all
```

在 `/experiments` 查看五日主指标、十日旁证、同口径父/基线对照，以及逐笔路径。列表中的 `upward_wave` 是冻结的小摘要，详情 `result.development.upward_wave` 为同一内容；逐笔数据在 `result.development.trades[].upward_wave`。旧交易结果快照 JSON 仍表示原交易模型，不混入未来波段收益。

四灯实验显示 `wave_observed`（有可评价波段数据）或 `wave_unverified`（暂无可评价数据），不以旧 `+3%` 命中或交易亏损门槛替代波段目标。它们不是策略通过/晋级结论；旧交易风险仍单独披露。未来显式运行留出评估也只报告新标签，不复用旧收益门槛宣称波段验证通过。污染标记仍优先保留。消费保留区间前必须确认父记录的引擎和构建与当前程序完全一致；版本不符会在创建运行记录之前拒绝，须先重跑开发基线。开发段与留出段不能互作数值提升对照。

上述排名实验的集合仍由原历史收益证据和机会分筛选，再按四灯过滤取 Top N；原样本成熟条件也沿用旧持有期限。**这是现有入场集合的波段质量，不是全市场每次四灯触发的无条件效果。** 波段标签没有用于训练排名或回灌到当日决策。

独立的 [全市场四灯研究](four-light-study.md) 通过 `cmd/four-light-study` 读取冻结的 `all-market.db`，取消排名、历史收益证据和 Top N 的样本限制。它复用同一开盘成交和费用；manifest v1 使用旧波段定义，v2 显式选择无回撤门槛定义，按当前可判的全市场股票日建立同日基准，单列首次全红、持续全红和转红灯类型，并保留未知分母。两类研究的样本集合不同，不能把比例变化直接解释成策略改善。

五日启动与20/40/60日延续可通过 `-wave-horizons` 研究，口径见[长期波段诊断](four-light-wave-horizons.md)；新窗口仅描述，不设回撤或成功门槛。
