# 模块实现方案索引

本目录按当前源码整理可重建规格。每篇采用 STAR：先说明边界，再列出完成条件，随后解释实现，最后给出证据和未验证项。文档中的公式、阈值、错误分类和输入输出字段来自 `3e2510b`（2026-10-28）；文件路径只是当前落点，重建时可以替换语言和目录，但不能改变外部行为。

这些文档描述已经存在的代码契约，不是下一阶段的产品路线图。源码优先；如果文档、测试和部署说明不一致，应先核对源码，再同步文档。模型分数、预测区间和历史统计都不是成功概率、收益承诺或投资建议。

## 最小验证

文档重写只检查源码契约和离线测试，没有连接生产行情、共享盘、微信公众号或真实部署。按模块执行定向测试：

```bash
go test -p 2 ./internal/monitor ./internal/market ./internal/storage ./internal/config
go test -p 2 ./internal/firststage ./internal/secondstage ./internal/selection
go test -p 2 ./internal/predictor ./internal/dayrange ./internal/wechat ./internal/notify
```

涉及网页、身份代理、容器和部署的验收仍需执行仓库规定的 `make dashboard-smoke`、`make docker-dashboard-smoke`、`make docker-smoke` 或真实部署检查；本次没有据此宣称线上可用。
