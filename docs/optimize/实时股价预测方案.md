# 实时股价预测方案

- 核对日期：2026-10-29
- 源码基线：`3e2510b`
- 实现位置：[`internal/predictor`](../../internal/predictor)、[`internal/config/predictor.go`](../../internal/config/predictor.go)、[`internal/storage/predictor.go`](../../internal/storage/predictor.go)
- 状态：代码已实现的实验能力；每次输出预测下一根 5 分钟线，不接入下单。

## S｜情境：只预测下一根已经定义的 5 分钟线

盘中预测需要在一根原生 5 分钟线收盘后，预测同一交易时段紧接着的下一根的最高、最低和收盘收益。正在形成的 bar 不能作为输入；11:30 的午盘收口和 15:00 的收盘 bar 没有同一时段的下一根目标。训练样本和在线推理共用同一时间连续性规则。

预测器从当天选股报告取正式入选股票；正式选择为空时退回观察排名 Top N。退回只改变预测观察集合，不改变正式推荐结果。预测、实际值、Kalman 趋势状态、模型 artifact 和投递账本分别持久化，方便重启后继续审计。

## T｜任务：完成 bar 到下一 bar 的三点预测

1. 输入 bar 必须 `Final=true`，目标结束时间正好为输入结束时间加 5 分钟，且目标仍在同一交易时段；目标 bar 在推理时尚未发生。
2. 交易时段为 09:30～11:30、13:00～15:00；输入结束于 11:30 或 15:00 时直接无效。服务从 09:35 起按 5 分钟槽运行，午休及收盘后跳过。
3. 标签和输出均是相对输入收盘价的收益率：`next_high/input_close-1`、`next_low/input_close-1`、`next_close/input_close-1`。不表示扣费后收益或可成交价。
4. `FeatureVersion=1` 固定 42 个特征，顺序写入 artifact；顺序或名称变化必须提升版本，旧 artifact 拒绝加载。
5. 训练只使用已有完整目标 bar 的历史样本。模型的 `valid_for` 控制生效日期：当天收盘前训练的模型不能学习当天 bar 来预测当天后续，训练后的模型通常从下一可预测日生效。
6. 数据库主键为 `(code, target_end_unix, model_id)`；同一模型重复循环幂等，但模型变更后同一目标 bar 可以留下不同模型的可审计记录。单轮若仅部分股票可预测，下一轮仍可补齐缺失股票。
7. 推送按目标 bar 聚合成一张预测卡片，偏差卡在目标 bar 到达后生成；推送失败保留预测和失败账本。

## A｜行动：特征、训练、推理与刷新

### 配置和生产开关

`DefaultPredictor()` 为 `enabled=false`、`push_enabled=false`、训练 `15:30`、`write_mode=loopback`、最少训练 5 天、验证 3 天、保留 10 个模型。生产 `config.Builtin()` 将 `Predictor.Enabled` 和 `Predictor.PushEnabled` 设为 `true`；环境覆盖仍受配置校验约束。

`write_mode` 只决定仪表盘 `PUT /api/predictor/config` 是否允许修改推送配置的请求来源：`off` 全部拒绝，`loopback` 只允许回环地址，`all` 允许通过请求头、Origin、Content-Type 等校验的来源。它不关闭预测、数据库写入或模型训练；是否排队消息由运行时 `push_enabled` 决定。

### 42 个版本化特征（FeatureVersion=1）

实际顺序由 `predictor.FeatureNames()` 固定：

- 分钟收益：`ret1/2/3/6/12/24`。
- 分钟振幅：`range1/3/6/12`。
- 当前 bar 形态：`close_pos`、`body`、`upper_wick`、`lower_wick`。
- 分钟量能与波动：`volume_ratio1/3/6`、`vol12`、`vol24`。
- 分钟趋势：`ma5_dist`、`ma12_dist`、`ma24_dist`、`rsi14`。
- 时间位置：`minute_of_session`、`bar_index`、`is_afternoon`。
- 同时刻股票池横截面：`pool_ret1`、`pool_breadth`、`pool_mean_range`。
- 日线背景：`day_ret1/5/20`、`day_ma5_dist`、`day_ma20_dist`、`day_vol20`、`day_volume_ratio`、`today_gap`。
- 价格尺度和可用性：`log_price`、`stock_day_vol20`、`has_24_bars`、`has_daily20`、`has_volume20`。

日线特征使用前复权日线；分钟输入、标签和实际值使用不复权价格。同一时间戳才参与股票池横截面，跨午休不计算连续窗口。历史不足以构造某项时保留 NaN/可用性标志，由树模型的缺失分支处理，不以前值填充。

### 模型和训练

artifact schema 为 2，包含 high/low/close 三组确定性梯度提升树、标签裁剪、损失函数、walk-forward 指标、残差带、训练日期、`valid_for`、特征名顺序和 checksum。通用默认训练参数为 120 棵树、深度 4、最小叶 40、学习率 0.05、L2=1、32 分箱、seed 1949；生产选项只将 close 的损失切为 L1，high/low 仍为 L2（用于保持区间覆盖表现）。模型训练不以单次“胜出基线”才保存，而是保存 walk-forward 评估和元数据，在线只加载校验通过且 `valid_for` 匹配当天的模型。

训练在选股报告可用后读取最多约 400 天分钟历史和两年日线背景；少于配置 `min_training_days` 的不同交易日会失败。训练期间若仍在收盘前，会剔除当天样本；找不到报告、历史不连续、模型 checksum 或特征结构不匹配时不替换当前有效模型。

### 推理、趋势和复盘

`PredictOnce` 每个轮询周期最多处理一个目标槽：先解析已到达的目标 bar，再检查交易日、模型日期和今日报告，批量构造特征并推理。Kalman 状态从 `kalman_state` 恢复，用于输出 `trend`、`confidence`、`trend_score`，它是上下文标注，不是额外的价格标签。输入特征不可用或输入收盘价非法时只跳过该股票；模型推理本身失败会终止本轮并记录错误，避免静默写入不完整结果。

预测写入 `predictions.db`（schema 3，SQLite DELETE journal、FULL synchronous），保存 `prediction`、`prediction_actual`、模型运行、Kalman 状态和延迟统计；状态与运行时推送开关分别写入 `state/predictor-status.json`、`state/predictor.json`。模型文件和 metadata 位于 `models/intraday/<model_id>/`，当前指针为 `models/intraday/current.json`，投递账本为 `state/predictor-delivery.json`。

目标 bar 到达后，以预测时基准价计算真实 high/low/close 收益。到收盘宽限期（5 分钟）仍无完整 bar 时写 `unresolved`，不会用零值填补；实际状态保存后才发送偏差卡。预测卡的投递有重试、blocked/expired 状态，关闭推送会使待投递事件过期，但不会删除预测记录。

## 重建规格

```text
BuildTrainingSamples(data) -> finalized contiguous samples + labels
Train(samples, model_info) -> schema-2 artifact + walk-forward metrics
PredictOnce(now, completed_minutes, report, artifact) -> batch predictions
Reconcile(target_end, completed_target_bars) -> resolved/unresolved actuals
Flush(ctx) -> aggregate prediction/deviation delivery ledger
```

`BuildInference` 只读输入结束时间及之前的分钟线、同一时间横截面和输入日期之前的日线；`BuildTrainingSamples` 对目标 bar 使用同样的 `Final`、5 分钟连续和交易时段约束。模块不启动行情下载器，也不把预测结果接入 `selection` 推荐或交易计划。

### 最小验收

| 用例 | 期望 |
| --- | --- |
| 输入 bar 未完成、时间为 11:30/15:00 或跨午休 | 不生成样本/预测 |
| 下一根缺失或时间不是 +5 分钟 | 样本被拒绝，不填充前值 |
| 当天训练数据被用于当天预测 | 训练剔除当天样本，模型 `valid_for` 不允许提前使用 |
| 特征顺序、版本或 checksum 改变 | 旧 artifact 加载失败 |
| 一只股票特征缺失 | 仅跳过该股票，其他股票继续 |
| 模型推理抛错 | 本轮失败并记录错误，不静默产生坏预测 |
| 同一模型重复调用 | 主键幂等；部分结果可在下一轮补齐 |
| `push_enabled=false` 或 `write_mode=off` | 前者停止投递，后者只禁止配置写入；预测落库规则不被改变 |
| 目标 bar 未完成/缺失 | 实际值保持 `unresolved`，误差统计不增加分母 |
