# 阳线回踩研究方案

本文按 `33ab655` 的源码核对，采用 STAR 描述离线研究契约。这里的“阳线回踩”是一套可重复扫描的规则，不是已经通过验证的交易策略；本文未运行真实历史数据研究，也不提供收益结论。

## S｜场景与边界

入口为 [`cmd/stock-watcher/yangpullback.go`](../../cmd/stock-watcher/yangpullback.go)，计算在 [`internal/yangpullback`](../../internal/yangpullback)。命令从本地行情库读取前复权与不复权历史、交易所日历，在内存中建立输入快照，输出 JSON。

```text
study-yang-pullback
  → 读取本地 qfq / none 日线及日历
  → 按股票、共同日期对齐
  → 扫描形态和对照信号
  → 不复权成交模拟
  → 日期切分、清除跨界标签、统计与 bootstrap
  → 变体、子组和稳健性描述
  → stdout JSON
```

这条路径不下载行情，不发送通知，不保存实验记录，不改变日常推荐。内存中的 `experiment.NewSnapshot` 不等于写入 `experiments.db`；需要研究档案时，应自行保存本次输出和对应构建版本。它与 [`存储快照与重放方案`](存储快照与重放方案.md) 的持久化报告重放不同。

## T｜完成条件与输入输出

### 命令和数据要求

```bash
stock-watcher study-yang-pullback -as-of 2026-10-28 -bootstrap 1000 -split 0.70
```

日期仅为语法示例，必须替换为本地数据实际覆盖的日期。`-as-of` 可省略，此时从前复权看板选择最新日期；`-bootstrap` 必须大于零，`-split` 必须严格介于 0 和 1。这些参数的命令归属和互斥由 [`main.go`](../../cmd/stock-watcher/main.go) 校验。

- 必须存在可读行情数据库，不能用缺库的 JSON 兼容目录代替。
- 日历必须覆盖截至日向前十个自然年的请求区间，闰日向有效日期收敛；命令不会联网补日历。
- 每只股票取 qfq 与 none 的共同日期，且最后共同日期必须等于 `as_of`；不满足的股票不进入有效配对。
- 少于 60 根的配对不能产生信号；没有可用配对时报错。
- “要求十年日历”不代表“拥有十年前复权行情”。`data` 中的数据跨度来自实际可用的共同历史，不能按请求窗口宣称十年样本。

默认检测参数：高点回看 10 根，回踩中间日数 2～5，阶段窗口 240，启用阶段要求。库级校验还要求高点窗口 3～120、回踩下限至少 1、上限不超过 20 且不小于下限、阶段窗口 60～1000；这些不是全部暴露给生产 CLI 的参数。

输出 `schema_version=1`、`rule=yang_pullback_v1`，包含 `definition`、`data`、`development`、`holdout`、`baselines`、`sensitivity`、`variants`、`subgroups`、`robustness`、`purged`、`verdict`、`limitations`。具体结构见 [`types.go`](../../internal/yangpullback/types.go) 和 [`evaluate.go`](../../internal/yangpullback/evaluate.go)。

### 结果必须满足的断言

1. 检测只使用信号日及之前的 qfq 数据，成交使用独立 none 数据。
2. 同一高点、同一锚定阳线只消费第一次满足形态的确认，不能重复计数。
3. 不可成交、未来数据不足和价格限制不明必须留在统计中，不能当盈利样本。
4. 开发区间标签不能跨入留出区间；后续变体不得声称拥有新的独立留出集。
5. 概率型比率为 0～1，收益为百分点，必须区分全部信号分母和已完成交易分母。

## A｜实现与判定顺序

### 1. 形态扫描

[`detect.go`](../../internal/yangpullback/detect.go) 首先验证日期严格递增、最后日期等于 `as_of`、OHLC 合法且数值有限。扫描从索引 59 开始；设当前确认位置为 `i`：

1. 在 `[i-HighWindow, i-PullbackMin-1]` 找最高 `High`，并列取最近一根，位置记为 `h`。
2. `pullback_days = i-h-1`，必须落在 2～5；它只统计高点与确认日之间的 K 线。
3. 从 `h` 向前寻找最近的 `Close > Open` 阳线作为锚点。锚点允许早于高点回看窗口。
4. 中间各日收盘不得高于高点的 `High`；守住锚点以 `Close >= anchor.Low` 判断，盘中最低价跌破并不单独否决。
5. 主形态要求中间收盘守住锚点，确认日收阳、收盘严格高于前一日最高价，且不低于锚点最低价。
6. 默认还要求截至确认日（含）最多 240 根计算出的阶段为 `advance`，阶段置信状态不是 `unknown`。

去重键是“高点日期 + 锚点日期”。代码在阶段过滤前标记已见：第一次满足结构的确认即使被阶段要求否决，也不会重新尝试同一 setup 的后续确认。这是当前扫描顺序的一部分。

对照模式共用高点与锚点搜索，并只在 `pullback_days=PullbackMin` 时取样：`hold_only` 要求守住锚点，但不要求确认日的阳线突破；`pullback_only` 也不要求守住。它们是各自生成信号的独立队列，不是逐笔匹配的因果对照。默认中间两根对应确认位置 `h+3`，不要将其误读为高点后的第二根。

### 2. 固定持有期主结果

[`evaluate.go`](../../internal/yangpullback/evaluate.go) 的主模拟默认 `Horizon=5`：信号的下一交易日买入，在买入后的第 5 个交易日收盘卖出。若中间没有假日，周一买入对应下周一收盘卖出；不是把买入日算作第 1 个退出日。

- 买价为开盘价加单边滑点后向上取分；无成交、日内价格范围小于 0.005、封板、疑似历史 ST 限制不明、预算不足或模拟买价超出最高价容差时不买入。
- 普通股票按 100 股一手、最低 100 股；科创板最低 200 股，之后按 1 股递增。
- 买卖计入佣金及最低佣金、过户费，卖出另计印花税。卖价为扣滑点后向下取分的收盘价，与当日最低价取较大值。
- 验证持有区间的交易日连续性；缺失退出数据、封死跌停、历史价格限制不明会保留未完成状态。
- 信号至退出区间内，qfq/none 比率相对变动超过 0.002 时标记 `corporate_action`，不能直接把复权价格当可成交价格。

主结果按扣费净收益严格大于零计胜，没有盘中止盈止损。附带的 `strategy.Simulate` 目标/止损诊断不改变主结果。主固定持有期也不应用 `MaxEntryGapPct`；限制 3% 入场跳空的是单独的 `gap_cap3_5d` 变体。

### 3. 统计、切分与 bootstrap

[`stats.go`](../../internal/yangpullback/stats.go) 的口径如下：

| 字段/指标 | 口径 |
| --- | --- |
| `win_rate` | 盈利笔数 / 全部信号数；跳过和未完成不计胜 |
| `win_rate_resolved` | 盈利笔数 / 已完成交易数 |
| 平均、净收益中位数 | 仅已完成交易，单位为百分点 |
| Profit Factor | 正净收益百分点之和 / 负净收益绝对值之和；无亏损时为 null |
| 股票、年份集中度 | 按全部信号计数，不能以盈利交易数代替 |

按主形态的不同信号日期排序，以默认 70% 选择开发/留出分界。开发侧若预计退出标签日期达到分界或未知，则清除该信号；预计退出是信号下一交易日再向后 `Horizon` 个交易日。对照组使用同一日期边界，但不强制信号日期或股票逐笔相同。

bootstrap 方法为 `independent_signal_date_moving_block_bootstrap`：仅对已完成且未跳过入场的交易按信号日期聚类，再从排序后的日期索引抽取循环连续块（可首尾环绕），默认块长 `Horizon+2=7`、迭代 1000、随机种子 1，输出 95% 区间。日期块不是连续交易日块，缺交易的日期不占位置；bootstrap 胜率分母是已完成交易。主形态和对照独立抽样，允许两组日期不相交；不能把差值区间解释为随机对照试验的因果效应。

主 verdict 按以下顺序形成：

| 门槛 | 当前要求 |
| --- | --- |
| 数据跨度 | 少于 2 年直接 `insufficient` |
| 留出样本 | 至少 100 信号、30 日期、20 股票 |
| 对照与区间 | 对照非空，双方及差值 bootstrap 可用 |
| 已完成胜率增量 | 相对对照至少 0.10，即 10 个百分点 |
| 主胜率差区间 | bootstrap 已完成交易胜率差值下界严格大于零 |
| 净收益 | 均值和中位数均大于零 |
| Profit Factor | 非 null 时至少 1.2；null 不单独触发此项否决 |
| 集中度 | 单股最多 20%；`data_years >= 2` 时，单年最多 40% |

`data_years` 按配对历史整体最早至最晚日期跨度除以 365.25 计算，不是跨过的自然年数量。跨度足够但任一条件失败为 `rejected`，全部通过为 `candidate`。`candidate` 仍是研究候选，不会触发生产推荐。

### 4. 探索性附加结果

[`variants.go`](../../internal/yangpullback/variants.go) 输出九类持有/退出变体：`fixed_5d`、`fixed_3d`、`fixed_10d`、`tp3_5d`、`sl3_5d`、`tp3_sl3_5d`、`tp5_sl3_10d`、`trail3_10d`、`gap_cap3_5d`。各自与使用相同退出规则的 `hold_only` 比较；先判断开盘越过止损、开盘越过目标，再判断盘中触发。只有盘中同时触发目标和止损时按止损优先，开盘已越过目标的分支不会被当日随后最低价覆盖。

敏感性输出包括高点窗口 20、以收盘高于 MA20 且 MA20 上行替代阶段要求，以及 1/3/10 日持有期；它们不能覆盖主规则的判定。

[`subgroups.go`](../../internal/yangpullback/subgroups.go) 比较回踩 2 日、回踩 5 日、锚点实体至少 5%、实体低于 2%、高阶段置信、60 日涨幅至少 20%、股池宽度至少 60% 等子组。股池宽度是当日收盘高于 MA20 的股票比例，至少需要 50 只有效股票，计算只使用当时及之前数据。

子组先在开发集按样本、净收益、胜率和同过滤对照筛选，再在既有留出集检查；输出 `confirmed` 也不等于新增一次独立样本外验证。数据已用于主结果和多种变体，必须保留多重比较限制。

[`robustness.go`](../../internal/yangpullback/robustness.go) 的年度分组、1～10 日持有曲线以及“最佳”字段都是同批数据上的描述，不能再据此选优后宣称未看过测试集。

### 5. 失败、取消与访问边界

无数据库、日历不覆盖、无有效配对、参数非法会返回错误，不联网修复。CLI 的 context 参与读取，但 `Evaluate` 本身没有 context 参数，扫描和 bootstrap 不提供逐步取消保证；不能把其他命令的 10 分钟实验超时套用到这里。

这是一条本机只读命令，没有登录态和管理员角色；文件访问由操作系统权限控制，没有专属网页状态。CLI JSON 中的空样本、未完成计数、verdict 和 limitations 才是使用者可见结果。

## R｜核对与验收

定向验证命令：

```bash
go test ./internal/yangpullback
go test ./cmd/stock-watcher -run TestStudyHistoryStartUsesFrozenTenYearWindow
```

既有测试覆盖：形态与模式差异、锚点超出窗口、同 setup 去重、未来数据隔离；不复权开收盘与费用、不可成交、锁跌停、ST 不明和公司行动；跨界标签清除；两种胜率分母、无损 PF 为 null、确定性块 bootstrap；变体止损优先、50 股宽度门槛和 1～10 日曲线。详见目录内 `detect_test.go`、`evaluate_test.go`、`stats_test.go`、`variants_test.go`、`subgroups_test.go`、`robustness_test.go`。

真实数据验收还应保存命令、构建 SHA、输入日期及配对数量，核对 `data` 跨度、开发/留出边界、purged 数和所有 verdict 理由。本文未证明任何股票、年份或策略通过上述门槛；定向测试与真实历史研究必须分开记录。
