# 套牢信号方案（v3）

核对基线：`feat/trapped-turnover-v3`，2026-11-02。本文描述精排候选的上方套牢压力诊断、换手衰减口径，以及它在公众号文章中的展示方式。该诊断不参与正式推荐、机会分、结构门控或交易执行。

## S｜情境：给精排候选增加可解释的上方成交压力说明

精排会输出下一交易日的研究候选，但原始排序只消费价量特征和离线分数，没有直接回答“现价上方是否还有一批近期成交、等待解套的筹码”。本方案用不复权日线 OHLCV、统一股数和日度换手率构造一个可复现的筹码代理，把每只候选的套牢压力附在报告和公众号文章中。

v2 的六项缺口在本版修正：

- 旧版把 120 天前成交与今天等权，早期筹码可能早已换手，套牢量系统性偏高；
- 旧版使用前复权典型价，除权后历史成本与现价不可比；
- 旧版把整日成交记在一个典型价，忽略日内高低点；
- 旧版直接使用 `volume_raw`，没有统一“手/股”；
- 旧版只看总套牢量和距离，远端历史高点可能误触发；
- 旧版剔除零成交日，停牌和零成交没有保留为“未换手”样本。

## T｜任务：固定输入、换手衰减、阈值和未知状态

### 输入

- **价格与成交量**：`market.History` 中 `adjust="none"` 的不复权日线。前复权只用于形态和排名，不用于成本。
- **换手率**：`market.DailyMetricHistory`，来源为搜狐或 BaoStock，字段 `TurnoverRatePct` 为百分比。生产链路在每日同步时抓取并缓存到 `<data_dir>/state/turnover-metrics.json`；报告输入会冻结同一份指标，`replay` 不重新联网。
- **成交量单位**：先通过 `market.ProviderVolumeShares(source, code, raw)` 换算为股数。新浪/BaoStock 已是股；腾讯主板为手、科创板为股；Tushare/东方财富为手。来源必须是已知 provider，且 `volume_unit="provider_raw"`，否则输出 `unknown`。

### 单日分布

每个正成交日按 `low → close → high` 的三角分布展开为 24 个基础价格桶，并在现价、现价上方 5% 和 15% 三个分档边界处继续切分：

- `low == high` 时退化为单点；
- 三角众数为收盘价；
- 每个桶的体积占比由三角分布 CDF 差分得到；
- 每个桶的体积占比由三角分布 CDF 差分得到，桶价格取区间中点，区间保留桶边界用于展示；
- 跨分档边界的成交先按价格切分成交量，再分别归入对应套牢区，禁止先按桶中心归类、再把价格裁到边界。

### 换手衰减

按时间从旧到新逐日处理：

1. 已有筹码乘以 `1 - min(max(turnover_rate_pct / 100, 0), 1)`；
2. 当日成交按三角分布加入；
3. 零成交日不做衰减，也不新增筹码，但保留在样本和展示中。

换手率覆盖所有正成交日才应用衰减。任一正成交日缺少有效换手率时，不静默按零衰减处理，而是输出 `unknown` 并保留 `baseline_trapped_volume_ratio`（未衰减套牢量）供对照。

公式为 `昨日剩余筹码 × (1 - 当日换手率) + 当日新增成交`；信号日新增成交不参与当日换手衰减，零成交日不衰减历史筹码。

### 流通股本口径校验

换手率只有在其分母（流通股本）稳定时才能跨日衰减。对每个正成交日，用换算后的成交股数除以 `turnover_rate_pct / 100` 推算流通股本，并检查相邻交易日的相对变化：

- 基础阈值为 10%；
- 上游换手率通常按 0.01 个百分点舍入，因此低换手率日会按 `0.005 × (1/前日换手率 + 1/当日换手率)` 放大容忍度，避免把舍入噪声误判为送转；
- 任一对相邻日超过有效阈值时，不跨该变化应用衰减，输出 `unknown`、原因 `turnover_share_base_changed`，并保留衰减前套牢量和最大推算股本变化供诊断。

### 指标定义

| 项目 | v3 口径 |
| --- | --- |
| 回看窗口 | 最近 120 个交易日 |
| 最低样本 | 至少 60 个交易日（包含零成交日），且至少 1 个正成交日 |
| 成本价 | 不复权价格 |
| 单日分布 | 低-收-高三角分布，24 桶 |
| 权重 | 换算后的成交股数 |
| 衰减 | 每日按换手率衰减已有筹码 |
| 上方套牢量 | 衰减后价格高于信号日收盘的筹码 / 衰减后总筹码 |
| 衰减前套牢量 | 同一价格口径、未应用换手衰减的套牢量 |
| 加权成本 | 上方筹码的成交量加权价格 |
| 成本带 | 上方筹码的 20%～80% 加权分位 |
| 浅度套牢区 | 现价上方 0%～5% 的筹码；区间取该档实际桶边界 |
| 中度套牢区 | 现价上方 5%～15% 的筹码 |
| 深度套牢区 | 现价上方 15% 以上的筹码 |
| 当前套牢区 | 加权成本所在档位：≤5% 浅度、≤15% 中度、>15% 深度 |
| 近端占比 | 浅度 + 中度套牢量 / 上方套牢总量 |
| 分区占比 | 三档上方筹码归一化；`share_pct` 用最大余数法取整，合计恒为 100 |

### 状态规则

| 状态 | 条件 |
| --- | --- |
| `triggered` | 衰减后上方套牢量 ≥ 30%，加权成本高于现价 ≥ 2%，且近端占比 ≥ 50% |
| `watch` | 衰减后上方套牢量 ≥ 20%，加权成本高于现价 ≥ 1%，且近端占比 ≥ 40% |
| `none` | 未达到观察阈值；总套牢量达标但近端占比不足时也归为 `none`，原因写 `near_term_share_below_threshold` |
| `unknown` | 日线少于 60 个交易日、没有正成交量、换手率缺失、推算流通股本口径发生显著变化、复权口径错误或成交量来源/单位不支持 |

`unknown` 只表示无法可靠计算，不能当作“没有套牢”。阈值是 v3 诊断常量，不进入正式推荐门槛；后续调整必须新版本化并补回归，不能静默改变历史报告含义。

## A｜行动：计算结果进入报告和公众号

1. `selection.attachTrappedSignals` 在精排完成后遍历 `report.Ranking` 和日线路径的 `report.Selected`，优先使用独立的 `TrappedRaw` 不复权历史；缺失时输出显式 `unknown`，不回退到前复权成本。`TrappedRaw` 至少保留最近 120 个交易日，不受较短的 `daily.history_days` 裁剪。
2. 结果写入 `Candidate.Trapped`，随报告 JSON 持久化；`selection.Input.TurnoverMetrics` 和 `storage.SyncItem.Turnover` 冻结同一份换手率，保证 `replay` 可复现。
3. 第二层公众号文章在每只精排候选的“价格与明日区间”中增加套牢信息，直接展示状态、衰减前后套牢量、当前套牢区和三档股价区间。例如：

   ```text
   套牢：触发31%/衰减前48%｜当前中度@16.10｜浅15.90~16.30(18%) 中16.40~17.20(52%) 深17.50~18.00(30%)
   ```

4. 候选不超过 6 只时，最多前 5 只展开独立“套牢盘诊断”小节，补充成本带、三档占比、换手覆盖、零成交日数和区间回撤；7 只及以上时使用单行紧凑格式，并将完整详情限制在前 4 只，避免超过微信 20,000 字符上限。
5. 文章统一说明 v3 口径：不复权成本、三角分布、换手衰减、零成交保留、近端占比门槛和三档合计 100%。
6. 整体结论会把触发或观察列为共同风险之一，但不改变“正式推荐/观察”的既有判断。
7. 旧 v1/v2 报告继续按字段降级展示，不重算、不回写；旧版成本文案不写“衰减后”，三档百分比在展示层重新归一化，没有有效价格区间时不显示“合计 100%”。新报告使用 `schema_version=3` 和 `method=turnover_adjusted_v3`。

## R｜结果与边界

- 成功路径：120 个交易日中 80 天在现价上方、30 天当前价格，换手率覆盖完整；衰减后套牢量 31%，衰减前 48%，当前套牢区为中度，浅+中度占比 70%，状态为 `triggered`。
- 零成交路径：60 个正成交日 + 60 个零成交日仍满足 60 日最低样本；零成交日不衰减已有筹码，并在 `zero_volume_sessions` 中展示。
- 换手缺失路径：正成交日缺少换手率时状态为 `unknown`，但保留 `baseline_trapped_volume_ratio` 供对照，不静默使用 v2 权重。
- 近端门槛路径：总套牢量 50%、加权成本高于现价 20%，但筹码全部在深度区时，近端占比 0%，状态为 `none`，原因写 `near_term_share_below_threshold`。
- 单位路径：同一股票腾讯 100 手与新浪 10000 股换算后应得到相同的 `total_volume_shares`。
- 股本变化路径：相邻日成交量不变而换手率减半时，推算流通股本翻倍，状态为 `unknown`，原因 `turnover_share_base_changed`。
- 分档边界路径：单个三角桶跨现价上方 5% 或 15% 边界时，桶内成交量按三角分布 CDF 拆分到两侧，区间不重叠。
- 公众号路径：每只文章候选的价格信息都带当前套牢区和三档股价区间；六只完整详情和十只紧凑候选在带套牢字段时，渲染后仍低于 20,000 字符。
- 不承诺：该信号不是实际持仓亏损，不是解套概率，不构成买卖建议，也不改变正式推荐或风险门槛。
