# 日内高低点预测方案

- 核对日期：2026-10-29
- 源码基线：`3e2510b`
- 实现位置：[`internal/dayrange`](../../internal/dayrange)、[`internal/config/dayrange.go`](../../internal/config/dayrange.go)、[`internal/storage/dayrange.go`](../../internal/storage/dayrange.go)
- 状态：代码已实现的实验能力；预测结果用于观察和复盘，不是推荐、成功概率或交易指令。

## S｜情境：在下一交易日开盘前冻结全天高低点预测

日常选股只回答“观察谁”。日内高低点模块单独回答：以最近一个已完成交易日为信息截止点，下一交易日的最高价和最低价可能落在哪里。输入必须冻结在参考日，不读取目标日行情；开盘后不补写同一目标日的盘前预测。

模块同时保存基线和候选模型的证据。候选模型没有通过门槛、模型文件损坏或单股推理失败时，仍可使用同一输入上的滚动分位基线。实际 K 线和交易状态确认后才记为已解析，缺失样本保留原因。

## T｜任务：冻结样本、按时间训练、生成并复盘

1. 目标日必须是参考完成交易日的下一交易日，并且调用时间早于目标日 09:30；日历必须覆盖该目标日。
2. 快照只使用目标日前的原始不复权日线、前复权特征、交易日历和停牌状态。上市前、非正价格、来源不一致、除权跳变、状态未知和历史不足的样本隔离，不补造 K 线。
3. 基线取参考日前最多 60 根日线，至少需要 20 根有效窗口；高低点分别计算边际分位区间，名义覆盖率为 80%，不是高低点同时覆盖的联合概率。
4. 候选模型按交易日切分训练、校准、验证；验证段必须同时满足点误差、区间覆盖、区间宽度和样本量门槛，否则预测继续使用基线。
5. 快照、模型运行、评估、预测和实际值写入 `dayrange.db`。相同目标日和股票的预测具有幂等 ID，重复调用保留原记录。
6. 复盘要求目标日已经完成、交易状态为已交易且原始目标 K 线完整；否则写入 `unresolved` 及原因，不把未完成样本当作零误差。
7. `GeneratePredictions` 只保存预测；定时 `Predict` 才排队投递。关闭日内高低点推送不会删除预测或复盘数据。

## A｜行动：特征、基线、模型和调度

### 配置与时间

`DefaultDayRange()` 为关闭状态（`enabled=false`），默认 `push_enabled=true`、训练 `15:40`、预测 `08:45`、复盘 `18:35`、历史 `365` 个日历日、保留 10 个模型；启用时历史范围为 180～7300 天，训练至少 60 个交易日，校准至少 10 天，验证至少 10 天。生产 `config.Builtin()` 沿用该模块关闭状态，需由环境或配置显式启用。

服务循环每 15 秒检查一次：预测窗口内生成下一交易日结果，训练在设定时间后为下一可预测日准备模型，复盘在设定时间后解析最近完成日。训练输入由行情读取接口一次加载，模型、快照和投递状态通过独立存储边界保存。

### 33 个版本化特征（FeatureVersion=1）

特征顺序由 `dayrange.FeatureNames()` 固定，变更必须提升版本并拒绝旧模型：

- 个股形态与区间：`prev_range_pct`、`prev_body_pct`、`prev_upper_wick_pct`、`prev_lower_wick_pct`、`prev_close_location`、`prev_return`、`prev_gap`、`range_mean_5/20/60`、`atr14_pct`。
- 个股收益、波动和位置：`return_1/5/20/60`、`volatility_5/20/60`、`volume_ratio_5_20`、`ma5_ma20_spread`、`ma20_ma60_spread`、`drawdown_20`、`distance_high_60`、`distance_low_60`。
- 市场层：`market_return_1`、`market_return_5`、`market_trend_20`、`market_volatility_20`、`market_breadth_5`。
- 板块层：`sector_return_5`、`sector_return_20`、`sector_relative_20`、`sector_breadth_5`。

个股、市场、板块层可分别关闭，但至少启用一层。不可用值以缺失值和 `Availability`（`available`、`insufficient_history`、`missing_sector`、`disabled`）表达；不会把缺失伪装成 0。个股与板块特征从前复权序列计算，标签和参考价使用同一来源的原始不复权序列。

### 基线

对参考日收盘价 `ref`，在最多 60 根原始日线中计算相邻日对数极值收益：

```text
high_return[i] = ln(high[i] / close[i-1])
low_return[i]  = ln(low[i]  / close[i-1])
high_point = max(ref × exp(q50(high_return)), ref)
low_point  = min(ref × exp(q50(low_return)), high_point)
```

`q10/q50/q90` 分别形成高点和低点的边际区间，模型标识为 `baseline_range_quantile_v1`，实现方法为 `trailing_quantile_60`。窗口有效样本不足时快照为 `snapshot_not_ready`，不会发布一个凭空的区间。

### 候选模型和门槛

模型为确定性的梯度提升树（artifact schema 1、`gbdt_conformal`）：默认 80 棵树、深度 4、最小叶 40、学习率 0.05、L2=1、32 个分箱、固定 seed 1949；分别拟合 high/low 的对数标签，标签裁剪为 ±0.5。校准阶段使用滚动残差共形分位（0.1/0.5/0.9），输出点估计和区间。

训练按日期切分，默认训练/校准/验证分别为 120/60/20 个交易日；不足时保存 `insufficient` 的基线运行。验证门槛是至少 20 个验证日、至少 100 个验证样本；high/low 点 MAE 均须比基线低 5% 以上，边际覆盖在 75%～85%，区间宽度不超过基线 110%，并保留联合覆盖指标。模型运行记录、评估、特征版本和 checksum 一起保存；加载失败会标记模型无效并回退基线。模型最多保留 `keep_models` 个（默认 10）。

### 数据和结果

`BuildPredictionSnapshots` 生成不可变的目标日快照，包含参考价、输入截止日、33 个特征、可用性、市场状态、波动分桶、基线和审计切片。预测记录包含 `prediction_id`、股票、目标日、模式、输入快照 ID、模型/基线来源、参考价、high/low 点值、q10/q50/q90、区间和创建时间。实际记录包含原始高低价、来源、解析状态和原因；评估按股票、市场状态和波动分桶汇总提交数、已解析数、未解析数及误差，未解析样本不进入分母。

## 重建规格

```text
BuildPredictionSnapshots(ctx, config, stocks, completed_data, target, now)
  -> frozen snapshots + unresolved reasons
BuildDataset(ctx, snapshots/data, as_of) -> immutable dataset + audit
Train(ctx, dataset) -> baseline run + candidate artifact + gate/evaluation
Predict(ctx, target[, code]) -> idempotent predictions + optional delivery
Reconcile(ctx, target) -> actuals (resolved/unresolved)
```

预测服务不下载行情；行情由 `MarketSource` 提供已冻结的 `MarketData`。生产写入要求共享存储和 `dayrange.db` 可用，数据库使用 SQLite DELETE journal、FULL synchronous；只读看板不能触发训练、预测或投递。

### 最小验收

| 用例 | 期望 |
| --- | --- |
| 目标日不是下一交易日或已过 09:30 | 拒绝预测，不写入目标日结果 |
| 缺少交易日历、停牌状态或原始目标 K 线 | 快照/实际值为未解析并保留原因 |
| 历史不足 20 根或未启用任何特征层 | 不产生可发布基线/配置校验失败 |
| 训练日、校准日或验证日不足 | 保存基线和不足原因，不晋级候选模型 |
| 候选 artifact checksum/特征顺序错误 | 标记无效并回退基线，其他股票继续 |
| 同一股票重复预测 | 返回 `already_published`，原记录不变 |
| 目标日尚未完成 | 不解析，不增加误差分母 |
| 关闭推送或调用 `GeneratePredictions` | 预测仍保存，投递账本无新增 |

## R｜结果：能力与证据边界

| 能力 | 代码证据 | 边界 |
| --- | --- | --- |
| 盘前冻结 | `completedAndNext`、开盘时间检查、快照只读目标日前数据 | 不提供盘中剩余区间预测 |
| 基线独立运行 | `baselineForecast` 与 `BaselineModelID` | 名义 80% 是边际覆盖，不是联合概率 |
| 候选模型可审计 | 日期切分、共形校准、`CheckGate`、checksum | 文档未声称历史精度已重新复跑 |
| 复盘不造数 | `Reconcile` 检查状态、来源和完整 K 线 | 未解析原因不会被平均误差掩盖 |
| 推荐与预测隔离 | 独立 `dayrange.db`、配置和投递路径 | 区间不能解释为买卖价或收益承诺 |
