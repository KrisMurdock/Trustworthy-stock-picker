# 四灯波段的同行业对照

`four-light-study` 可在 manifest v2 上增加冻结行业分类。原四灯、入场、无回撤否决波段标签和基础报告不变；新增结果只用于研究行业轮动与首次全红所处阶段，不接入排名或正式推荐。

## 分类输入

`-classification` 与 `-classification-sha256` 必须成对提供。JSON 最大8 MiB，严格校验未知字段、日期、唯一有序成员、来源与摘要；摘要不一致则终止，不能静默换分类重跑。

```json
{
  "schema_version": 1,
  "basis": "published_snapshot",
  "taxonomy": "capco_2025h2",
  "level": "section_plus_division",
  "snapshot_as_of": "2025-12-31",
  "published_on": "2026-04-03",
  "observed_at": "2026-11-02T21:00:00+08:00",
  "sources": [{"url": "https://example.org/classification.pdf", "sha256": "替换为原文件64位小写SHA256"}],
  "memberships": [{"code": "sh600000", "sector_code": "J66", "sector_name": "货币金融服务"}]
}
```

`snapshot_as_of` 表示报告期末，不代表成员生效时间；`published_on` 是有来源支持的发布日期；`observed_at` 是本次下载时间。只有日期、没有准确发布时刻时，保守要求信号日严格晚于发布日期。全期固定使用一个分类版本，不能声称每日历史成员完全正确。

`current_only` 只能进行显式标记的回溯描述，必须省略 `published_on`，不能产生可用于历史候选的强弱组。缺分类保持未知，不用今天的分类补历史。成员按股票代码严格升序、唯一；同一行业代码必须对应同一名称。交易板块、行业和热门主题是不同概念。

## 固定诊断口径

- 信号日及之前严格连续21个冻结交易日的前复权收盘，计算20日涨幅。缺任意一日则未知，不用旧行情替代。
- 参照来自当前四灯可判且先验价格完整的股票；不按未来是否买入、路径是否完整或是否成功筛选。
- 行业与市场均使用等权平均，并排除该股票自身；至少需要5只其他有效参照。这是覆盖下限，不是优化参数。
- 分别比较首次全红中的“个股20日涨幅高于同行业”和“不高于同行业”，以及“同行业高于市场”和“不高于市场”。只以严格大于零划分，两个条件各自评价，不与量比条件组合。
- 未来5日为主，10日另报；缺价格、分类或参照者保留原信号分母及未知原因。仍不设回撤阈值。

行业分组、先验特征、未来结果分开计算。两次逐股扫描不保留全市场未来价格路径；事件文件仍只输出原有全红事件，附加行业与信号日上下文。

## 同日同行业比较

每个有效候选与同一信号日、同一行业中其他有效股票比较。设某行业日基准有效数为N、成功数为B，候选有效数为C、成功数为S，则去掉各候选自身后的差值合计为：

```text
S - (C*B-S)/(N-1)
```

要求N−1至少5；不足或分类缺失的候选单列未匹配数量，不填零。先按当日候选行业构成加权，再将有匹配样本的日期等权平均。不能拿行业简单平均冒充候选构成，也不能对不同日期集合的差值直接相减。同时保留同日市场、未筛选首次全红及逐月对照。

10交易日移动块、2,000次重采样仅提供描述性区间。规则建立在已经反复观察的开发期上；增加行业解释不会恢复独立验证性质。分类滞后、当前活跃股池、事后冻结复权版本、未知样本不随机等限制仍然存在。

## 运行

```bash
four-light-study -manifest manifest.json -database all-market.frozen.db \
  -classification classification.json -classification-sha256 <冻结文件摘要> \
  -events sector-events.jsonl -timeout 1h > sector-report.json
```

输出沿用 `report`，额外提供 `classification_file_sha256` 和版本化 `sector_context`。分类来源与参数随报告保存；事件不得覆盖任何输入或已有文件。工具不访问网络、不写行情库、不读取预留区间。省略分类参数时保持原行为。
