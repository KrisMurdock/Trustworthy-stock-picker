# 5 分钟预测方向分类器评估（2026-10-22）

本轮验证的是 close 方向分类器，而不是新的 high/low/close 回归特征。结论先行：**全局符号修正没有达到合并标准，生产模型保持不变；高置信子集存在选择性方向信号，值得作为下一轮研究对象。**

## 1. 范围与口径

- 验证区间：2026-09-21 至 2026-10-20，16 个交易日。
- 股票池：149 只 `config-diagnostic` 股票；每个验证日 6,854 条样本，共 109,664 条。
- 模型：FeatureVersion 1 的 B0 expanding 基线；为控制机器资源，训练窗口限制为最近 60 个交易日，约 40.9 万条训练样本。
- 指标：close/high/low 为日等权 MAE，单位 bps；close 方向只统计实际收益非零样本，预测为 0 计错；bootstrap 按验证日重采样 10,000 次。
- 该口径使用当前股池，存在幸存者偏差，不是正式 point-in-time 样本外验收；60 日训练窗口也与生产全历史重训不同。

## 2. 基线

| 指标 | 结果 |
| --- | ---: |
| close MAE | 25.9211 bps |
| 预测 close=0 的 MAE | 25.8358 bps |
| high MAE | 18.0956 bps |
| low MAE | 15.2764 bps |
| close 方向准确率 | 52.34% |
| 多数类准确率 | 54.19% |
| balanced accuracy | 51.87% |
| MCC | +0.035 |

B0 的 close 点误差仍略差于“预测 0”，说明 close 幅度信息很弱；high/low 的误差明显小于 close。

## 3. 全局符号修正

默认候选阈值 `0.02`：当 `abs(probability-0.5) >= 0.02` 时，用分类器概率决定 close 符号，幅度保留 B0 的绝对值。

| 指标 | 结果 | 变化 |
| --- | ---: | ---: |
| close MAE | 25.8927 bps | -0.0284 bps，95% CI [-0.0939, +0.0465] |
| close 方向准确率 | 53.50% | +1.16 pp，95% CI [+0.13, +2.15] |
| 多数类准确率 | 54.19% | 仍低于多数类 |
| balanced accuracy | 51.78% | 未改善 |
| MCC | +0.039 | 仅小幅变化 |
| MAE 改善天数 | 12/16 | 不稳定 |

阈值敏感性：

| threshold | 覆盖率 | close MAE 变化 | 方向准确率 |
| ---: | ---: | ---: | ---: |
| 0.005 | 93.5% | -0.0481 bps | 53.77% |
| 0.020 | 74.4% | -0.0284 bps | 53.50% |
| 0.050 | 39.3% | -0.0296 bps | 53.16% |
| 0.070 | 21.8% | -0.0203 bps | 52.79% |

MAE 的 95% 区间在 0.02 和 0.05 均跨 0；方向准确率虽然改善，但始终低于多数类。**不能据此替换生产 close 点预测。**

## 4. 高置信子集

按分类器置信度 `abs(probability-0.5)` 分层后，高置信样本的条件准确率明显高于低置信样本：

| threshold | 覆盖率 | 覆盖样本 | 分类器准确率 | B0 准确率 |
| ---: | ---: | ---: | ---: | ---: |
| 0.020 | 74.4% | 75,695 | 54.43% | 52.89% |
| 0.050 | 39.3% | 39,801 | 55.39% | 53.32% |
| 0.070 | 21.8% | 22,046 | 55.86% | 53.80% |
| 0.100 | 6.7% | 6,709 | 56.31% | 54.85% |

在 `0.07` 门限下，覆盖约 21.8% 的样本，条件准确率 55.86%，高于多数类 54.19%。这更适合作为“是否展示方向判断/是否进入观察”的选择性信号，而不是覆盖全部样本的符号修正。

## 5. close 幅度缩放

同一批 B0 预测上，仅缩放 close 幅度、不改 high/low：

| close scale | close MAE | 变化 | 95% CI | MAE 改善天数 |
| ---: | ---: | ---: | ---: | ---: |
| 0.50 | 25.8586 | -0.0624 bps | [-0.1324, -0.0035] | 11/16 |
| 0.75 | 25.8837 | -0.0374 bps | [-0.0734, -0.0077] | 12/16 |
| 0.90 | 25.9047 | -0.0163 bps | [-0.0309, -0.0045] | 12/16 |
| 1.00 | 25.9211 | 0 | — | 0/16 |

缩放的区间不跨 0，但收益幅度很小；它更适合作为下一轮的独立校准实验，而不是与方向修正一起直接上线。

## 6. 结论

- 全局方向符号修正：**不合并**。MAE 改善不显著，方向准确率仍低于多数类，balanced accuracy 未改善。
- 高置信方向信号：**保留研究**。`0.07` 门限下约 22% 覆盖率、55.86% 条件准确率，值得研究成选择性展示或过滤特征。
- close 幅度：B0 的幅度信息弱，`close=0` 或 0.5～0.75 缩放可小幅降低 MAE；应单独验证，不要与方向修正混在一起。
- 生产模型未替换，FeatureVersion 1 和现有 artifact 行为不变。

## 7. 下一轮优先级

1. **close 幅度校准**：在更长、正式 point-in-time 样本上验证 0.5/0.75 缩放；同时报告方向、MAE 和 high/low 包络，避免只看一个指标。
2. **选择性方向信号**：把方向概率作为高置信过滤器，报告覆盖率、条件准确率与弃权比例；不要默认覆盖全部 close 符号。
3. **概率校准与置信度分离**：Go 逻辑回归的置信度分布比 Python 探索版更压缩；需要比较训练样本上限、L2、迭代次数和概率校准，先让高置信分层稳定。
4. **幅度/分位数模型**：close 回归的幅度信息弱，优先研究分位数或区间模型，而不是继续在同一个点回归上堆特征。
5. **正式数据边界**：补 point-in-time 股池、行业归属和更长验证窗口；当前 `config-diagnostic` 结果不能当作线上收益证明。

## 8. 复现

```bash
STOCK_WATCHER_DATA_DIR=<data_dir> \
STOCK_WATCHER_REQUIRE_CIFS=true \
STOCK_WATCHER_FEISHU_ENABLED=false \
STOCK_WATCHER_POOL_FILE=<149只股池> \
go run ./cmd/stock-watcher predictor-eval \
  -as-of 2026-10-20 \
  -baseline-only \
  -universe config-diagnostic \
  -validation-days 16 \
  -max-training-days 60 \
  -direction-threshold 1 \
  -dump-predictions /tmp/pred16.jsonl
```

`-direction-threshold 1` 导出未修正的 B0 close 和 `direction_probability`；随后在离线脚本中按阈值重放符号修正，避免为每个阈值重复训练。
