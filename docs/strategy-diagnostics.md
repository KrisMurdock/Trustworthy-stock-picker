# 推荐门槛诊断

飞书的观察排名和网页日推排名现在共用报告诊断。诊断读取报告中保存的规则统计与当时参数，解释实际拒绝原因；不重新回测、不改排名、不改推荐结论，也不覆盖保存的报告或通知账本。

## 如何阅读

| 提示 | 含义与处理方向 |
| --- | --- |
| 未触发买入规则 | 当日仅匹配股池基准，未匹配突破、回踩、动量或量能恢复。基准用于比较，不构成入场信号。 |
| 入场样本/不同信号日不足 | 展示实际数量和当时要求（默认 60 个入场样本、40 个不同信号日）。核查分析历史与有效样本；重复下载相同日期不会增加独立信号日。 |
| 未决交易 | 模拟持有路径不完整、存在复权事件等，不能当作安全或盈利样本；显示实际笔数，要求为零。 |
| 平均净收益/达标率未达标 | 显示实际收益、达标率和股池基准。样本够多仍可能不满足收益要求。 |
| 历史单笔净亏损超限 | 匹配规则在全股池历史样本中出现单笔净收益小于或等于 -3%。显示超限笔数和最差净收益；这些统计不代表该候选股票本身的历史亏损。 |
| 独立验证暂无结论：无合格推荐样本 | 已有验证区间，但没有通过规则准入的入场样本；收益统计不可用，不解释为 0% 胜率。 |
| 独立验证未建立 | 历史信号不足以形成冻结的保留区间，需配套核查分析窗口、交易日历和完整持有期。 |
| 独立验证未通过 | 列出实际未达标项；默认需要至少 30 个推荐入场、10 个不同信号日、无未决/亏损超限、正平均净收益，并在达标率与平均净收益上优于股池基准。 |
| 统计缺失 | 老报告缺少规则统计、基准或有效参数，无法重建具体比较。保留已存结论，不用当前配置猜测历史阈值。旧报告缺少精确亏损次数时标为“至少1笔”，不伪造次数。 |
| 缠论门控：通过 | 5m、15m、30m 三级结构均满足；该股票未被缠论过滤，仍须通过历史证据与风险门槛才可能成为正式推荐。 |
| 缠论门控：未通过 / 未知 | 未通过会给出具体级别和原因；未知表示分钟路径不完整或结构不足。两者都只保留观察排名，不进入正式推荐，未知不按通过处理。 |
| 评分推导 | 展示机会分的实际算式：基础 25、日线评分×0.25、MA20 上行/强于股池/收盘偏强/量能适中/波动适中各 +10、偏离过大 -20、上影线过长 -10；再按历史证据下界融合或折半。 |

独立验证的结论作用于整份报告，在飞书“研究与验证”和网页排名上方集中展示。个股风险列保留其规则问题；网页展开规则后可查看全部失败条件。零入场或零已退出样本的通知显示“暂无可统计收益”。

## 风险与数据口径

止损触发目标和历史风险准入分别校验：历史准入仍要求每笔净收益严格高于 -3%，包含等于 -3% 的边界；模拟跳空、无法卖出和费用可能导致实际退出超限。此项修复没有放宽风险、收益、样本数或独立验证门槛，观察排名也不会被转为正式推荐。

`daily.history_days` 控制前复权分析窗口。十年不复权归档不等于已经具备十年分析样本；扩展训练期需要同跨度的前复权数据和已核实的交易日历。增加数据不能消除已发生的亏损，也不能让弱规则自动获得优势。规则修改仍应在开发区完成，再使用保留区间验证。

## 兼容与运行

`/api/dashboard` 的 `report` 和 `/api/reports` 返回的报告附加 `diagnostics`，内部 `schema_version: 1`。字段包括整体验证、按股票代码索引的候选诊断、规则名、实际值、要求值、比较符号和中文解释；缺失研究的旧趋势报告不附加该字段。原报告 schema、排名、标识和研究参数不变，数据库无需迁移。前端未获得诊断字段时保留原有标签，并提供完整中文翻译。

部署新二进制后，网页读取旧报告即可获得诊断。已发出的飞书卡片不会被追溯修改；后续正常生成的卡片使用新展示，已持久化的待重试消息保持原内容。

验证包括实际报告回放、规则阈值与亏损边界测试、缺参数/旧统计兼容、两个 API 的一致性与无修改断言，以及真实 Chromium 的规则明细、零样本状态、历史日期切换、移动布局和错误恢复。飞书集成使用本地 HTTP 模拟端点。
