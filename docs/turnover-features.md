# 换手率与成交额特征研究

`cmd/turnover-study` 是研究型命令，用来回答一个受控问题：在现有第一层日线特征上追加换手率、成交额和流动性派生特征，是否改善同一套交易标签下的样本外收益。它不修改生产报告、不训练生产 artifact、不发送通知，也不把研究统计表述为未来收益承诺。

## 数据口径

- 换手率 `turn` 和成交额 `amount` 来自 BaoStock `query_history_k_data_plus` 的日线字段，与现有 OHLCV 查询分离，不改变 `market.Bar` 契约。
- `turnover_rate_pct` 沿用 BaoStock 百分比语义，例如 `0.3328` 表示 `0.3328%`；`amount_cny` 为人民币元。
- 成交额单位已用贵州茅台等样本与腾讯不复权日线的 `成交量 × 收盘价` 交叉核对，比值约 `0.99`；仍应在扩大股票池后持续校验。
- 缓存写入 `.scratch/turnover-study/metrics.json`，只保存研究数据，不进入生产库和发布包。
- 特征只使用信号日及以前最近 20 个观测；缺少信号日当日观测、历史不足 21 条或出现非正值时直接跳过该股票日，不用价格和成交量反推流通股本。

## 特征

基线代理特征与生产 `firststage` 的 8 个特征同序：

`atr14_pct`、`low20_distance`、`return5`、`rsi14`、`touch_rate20`、`base_score`、`volume_ratio`、`high20_distance`。

追加的 10 个流动性特征：

| 特征 | 含义 |
| --- | --- |
| `log_turnover_rate` | 当日换手率水平 |
| `log_turnover_ratio_5` | 当日换手率 / 5 日均值 |
| `log_turnover_ratio_20` | 当日换手率 / 20 日均值 |
| `log_turnover_5_20` | 5 日均换手率 / 20 日均换手率 |
| `turnover_z_20` | 当日换手率相对 20 日分布的 z-score |
| `turnover_cv_20` | 20 日换手率变异系数 |
| `log_amount` | 当日成交额水平 |
| `log_amount_ratio_5` | 当日成交额 / 5 日均值 |
| `amount_z_20` | 当日成交额相对 20 日分布的 z-score |
| `log_float_mcap` | 由 `成交额 / (换手率 / 100)` 估计的流通市值，作为规模控制变量 |

`log_float_mcap` 是点时估计值，不是交易所披露的流通股本；它只用于横截面规模控制，不进入生产展示。

## 验证协议

1. 基线组只使用 8 个代理特征；候选组追加 10 个流动性特征。两组都按日做横截面标准化。
2. 标签使用仓库现有 `strategy.Simulate`：信号日收盘后排名，下一交易日开盘加滑点买入，3% 净目标、3% 净止损、费用与 T+1 规则，默认持有 5 日。
3. 采用 purged walk-forward：训练标签的退出日必须严格早于评估日，避免评估日自己的结果进入训练。
4. 默认评估 Top5；按持仓期长度做 2,000 次循环块 bootstrap，比较两个模型的日度槽位收益差。5 日配置使用 5 日块，3 日配置使用 3 日块，避免把重叠持仓的日收益误当成独立样本。
5. 安慰剂对照把每个交易日的流动性特征块跨股票随机置换，保留联合分布但破坏股票对应关系；候选模型仍有同样多的额外参数，因此可以区分“真实流动性信息”和“单纯增加特征容量”。

## 复现

从仓库根目录运行，使用与生产一致的股池和数据目录：

```bash
STOCK_WATCHER_FEISHU_ENABLED=false \
STOCK_WATCHER_WEB_ENABLED=false \
STOCK_WATCHER_REQUIRE_CIFS=false \
go run ./cmd/turnover-study \
  -data-dir /path/to/stock_watcher/data \
  -through 2026-10-26 \
  -workers 6 \
  -bootstrap 2000 \
  -offline
```

首次运行去掉 `-offline` 会拉取并缓存 BaoStock 日度指标。稳健性检查只建议有限组合：

```bash
# Top10
go run ./cmd/turnover-study -data-dir /path/to/data -through 2026-10-26 -top 10 -offline

# 3 日持有
go run ./cmd/turnover-study -data-dir /path/to/data -through 2026-10-26 -horizon 3 -offline

# 安慰剂：置换当日流动性特征块
go run ./cmd/turnover-study -data-dir /path/to/data -through 2026-10-26 -placebo-seed 1 -offline
```

默认报告写入 `.scratch/turnover-study/report.json`。`-from` 缺省时会保留 65 个交易日特征预热；`-min-train-days` 默认 40；`-retrain-every` 默认 5。

## 2026-10-26 结果

本次数据为 193 只股票、191 只进入特征样本、47,807 条 BaoStock 日度指标，缓存区间 `2025-10-14` 至 `2026-10-26`。信号日 180 个，评估日 134 个，评估区间 `2026-03-30` 至 `2026-10-16`。特征行 33,795 行，已决标签 24,873 行（73.60%），正收益标签 11,531 行（已决样本的 46.36%）。未决主要来自 20,000 元预算下的最低买入金额不足和高开/一字板跳过。

| 配置 | 基线平均槽位净收益 | 候选平均槽位净收益 | 增量 | 持仓块 bootstrap 95% 区间 |
| --- | ---: | ---: | ---: | --- |
| Top5 / 5 日（主配置） | -0.536% | -0.024% | **+0.512pp** | +0.215% ～ +0.819%，正向率 99.95% |
| Top10 / 5 日 | -0.245% | -0.184% | +0.061pp | -0.117% ～ +0.235%，正向率 74.3% |
| Top5 / 3 日 | -0.440% | -0.157% | +0.283pp | +0.0004% ～ +0.565%，正向率 97.7% |
| 安慰剂 seed 1 | -0.536% | -0.409% | +0.127pp | -0.051% ～ +0.311% |
| 安慰剂 seed 2 | -0.536% | -0.449% | +0.087pp | -0.102% ～ +0.266% |
| 安慰剂 seed 20261026 | -0.536% | -0.431% | +0.105pp | -0.085% ～ +0.305% |

主配置中，基线与候选的已成交交易平均净收益分别为 `-1.222%` 和 `-0.041%`；胜率 `36.73%` 对 `47.86%`，目标触达率 `36.39%` 对 `47.86%`，止损率 `34.35%` 对 `27.71%`。按 5 个评估日分组的 27 个 cohort 的复利结果分别为 `-13.92%` 和 `-1.39%`，最大回撤分别为 `-14.31%` 和 `-8.23%`。

候选组把 Top5 槽位中的“资金不足”从 190 次降到 104 次，把“高开/一字板跳过”从 186 次降到 169 次。即使只看已成交交易，候选组的平均净收益仍明显更好；因此改善不只是提高了成交率。

最后一次重训的标准化系数中，`log_turnover_rate`、`log_amount_ratio_5`、`amount_z_20` 为正，`log_float_mcap`、`log_amount`、`turnover_z_20` 为负。方向与“适度放量、偏小市值、避免自身换手率极端化”的解释一致，但单次系数不能替代稳定性和因果验证。

## 解释与限制

- **Top5 的相对改善成立，绝对收益不成立。** 主配置显著高于三个安慰剂种子，3 日持有方向也一致；Top10 的增量只有 `+0.061pp` 且区间跨 0，说明改善集中在更集中的 Top5，不能声称所有仓位规模都有效。所有配置的基线组和候选组平均净收益都为负，候选组主配置的 cohort 复利仍为 `-1.39%`。不能据此宣称策略已经可以稳定盈利。
- **不是生产第一层模型的精确复现。** 基线是同样的 8 个特征重新拟合的 logistic 代理，生产 `firststage` 是冻结的 `future_three_day_max_high_touch_1pct` artifact；本研究的标签是 3% 目标/3% 止损/5 日持有。结论只回答“在这套特征和标签下，追加流动性特征是否有增量”，不能直接换算成生产模型的提升。
- **样本只覆盖一个市场阶段。** 只使用当前库中约一年的前复权窗口和当前 193 只股票池，存在股票池选择偏差和单一市场阶段偏差；需要多年度、跨市场状态和更大股票池复验。
- **预算与跳空风险是主要拖累。** 20,000 元预算使高价股无法买入；3% 止损无法约束跳空和跌停退出，最差单笔约 `-17.09%`。提高预算、按信号日价格过滤不可买股票、或单独建模跳空风险，可能比继续加特征更重要。
- **未接入生产。** 当前没有新增 `market.db` 表、没有把 `turn/amount` 写入生产同步链路、没有升级 `firststage`/`secondstage` 特征版本，也没有生成新的生产 artifact。研究结论不会自动进入推荐或通知。

## 下一步

1. 把验证窗口扩展到至少 3～5 年和多个市场状态，并保留固定 holdout，不在同一区间反复调参。
2. 用生产第一层的 `+1% 三日最高价触达` 标签重训候选模型，再单独评估下游 3% 目标策略的净收益，区分“排序能力”和“交易收益”。
3. 做预算敏感性：20,000、50,000、100,000 元，并在信号日过滤无法买入的最低一手股票，避免把成交率改善误读为选股收益。
4. 只有在多年度样本外、安慰剂和预算敏感性都通过后，才设计 `market.db` 日度指标表、同步任务、schema 迁移、特征版本升级和 artifact 重训。

研究统计不是成功概率、收益承诺或投资建议。
