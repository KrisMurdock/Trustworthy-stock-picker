# 换手率与成交额特征研究

`cmd/turnover-study` 是研究型命令，用来回答一个受控问题：在现有第一层日线特征上追加换手率、成交额和流动性派生特征，是否改善同一套交易标签下的样本外收益。它不修改生产报告、不训练生产 artifact、不发送通知，也不把研究统计表述为未来收益承诺。

## 数据口径

- 前复权 OHLCV 默认通过新浪公开历史接口及复权因子拉取，缓存写入 `-bar-cache`；日度换手率 `turn` 和成交额 `amount` 通过搜狐历史行情接口拉取，缓存写入 `-cache`。两条路径都不修改 `market.Bar`、`market.db` 或生产同步链路。
- `turnover_rate_pct` 使用百分比语义，例如 `0.3328` 表示 `0.3328%`；搜狐成交额原始单位为万元，解析后统一换算为人民币元。新增上市首日等缺失换手率的 `-` 行会跳过，不用价格和成交量反推。
- BaoStock 日度指标客户端仍保留在 `internal/market` 供交叉核对，但不再是该研究命令的默认数据源；公共 TCP 会话在多年份并发查询时容易限流，不能作为长窗口复验的单点依赖。
- 缓存只写入 `.scratch/turnover-study/`，逐只成功后原子落盘，进程中断后保留已完成股票；不进入生产库和发布包。
- 特征只使用信号日及以前最近 20 个观测；缺少信号日当日观测、历史不足 21 条或出现非正值时直接跳过该股票日，不用价格和成交量反推流通股本。

## 特征

基线代理特征与生产 `firststage` 的 8 个特征同序：

`atr14_pct`、`low20_distance`、`return5`、`rsi14`、`touch_rate20`、`base_score`、`volume_ratio`、`high20_distance`。

流动性特征按语义分为四组，`-feature-set` 决定候选组追加哪些组：

| 组 | 特征 | 含义 |
| --- | --- | --- |
| `turnover` | `log_turnover_rate` | 当日换手率水平 |
|  | `log_turnover_ratio_5` | 当日换手率 / 5 日均值 |
|  | `log_turnover_ratio_20` | 当日换手率 / 20 日均值 |
|  | `log_turnover_5_20` | 5 日均换手率 / 20 日均换手率 |
|  | `turnover_z_20` | 当日换手率相对 20 日分布的 z-score |
|  | `turnover_cv_20` | 20 日换手率变异系数 |
| `amount` | `log_amount` | 当日成交额水平 |
|  | `log_amount_ratio_5` | 当日成交额 / 5 日均值 |
|  | `amount_z_20` | 当日成交额相对 20 日分布的 z-score |
| `amount-level` | `log_amount` | 仅成交额水平 |
| `amount-dynamics` | `log_amount_ratio_5`、`amount_z_20` | 仅成交额变化与偏离 |
| `float_mcap` | `log_float_mcap` | 由 `成交额 / (换手率 / 100)` 估计的流通市值，作为规模控制变量 |

`-feature-set` 的取值为：

- `full`（默认）：基线 8 特征 + 全部 10 个流动性特征，顺序与原报告一致；
- `turnover`：只追加换手率 6 特征；
- `amount`：只追加成交额 3 特征；
- `amount-level`：只追加 `log_amount`；
- `amount-dynamics`：只追加成交额变化 2 特征；
- `amount-size`：追加成交额 3 特征和 `log_float_mcap`。

消融模式只改变候选模型追加的特征组，基线特征、标签、训练切分和成交模拟完全不变。

`log_float_mcap` 是点时估计值，不是交易所披露的流通股本；它只用于横截面规模控制，不进入生产展示。

## 验证协议

1. 基线组只使用 8 个代理特征；候选组按 `-feature-set` 追加对应流动性特征。默认 `full` 追加全部 10 个特征；消融组用于判断增量来自换手率、成交额水平、成交额变化还是规模控制。两组都按日做横截面标准化。
2. 标签使用仓库现有 `strategy.Simulate`：信号日收盘后排名，下一交易日开盘加滑点买入，3% 净目标、3% 净止损、费用与 T+1 规则，默认持有 5 日。
3. 采用 purged walk-forward：训练标签的退出日必须严格早于评估日，避免评估日自己的结果进入训练。
4. 默认评估 Top5；按持仓期长度做 2,000 次循环块 bootstrap，比较两个模型的日度槽位收益差。5 日配置使用 5 日块，3 日配置使用 3 日块，避免把重叠持仓的日收益误当成独立样本。
5. 安慰剂对照把每个交易日的流动性特征块跨股票随机置换，保留联合分布但破坏股票对应关系；候选模型仍有同样多的额外参数，因此可以区分“真实流动性信息”和“单纯增加特征容量”。

## 复现

从仓库根目录运行，使用与生产一致的股池和数据目录：

```bash
STOCK_WATCHER_FEISHU_ENABLED=false \
STOCK_WATCHER_WEB_ENABLED=false \
STOCK_WATCHER_REQUIRE_CIFS=false \
go run ./cmd/turnover-study \
  -data-dir /path/to/stock_watcher/data \
  -through 2026-10-26 \
  -years 5 \
  -feature-set full \
  -budget 20000 \
  -workers 4 \
  -metric-workers 2 \
  -bootstrap 2000 \
  -bar-cache .scratch/turnover-study/qfq-bars-5y.json \
  -cache .scratch/turnover-study/metrics-5y.json \
  -offline
```

首次运行或扩大年份窗口时去掉 `-offline`，命令会拉取缺失的前复权 K 线和日度指标并逐只写缓存。`-years` 允许 1～10 年；`-metric-workers` 只控制日度指标并发，默认 1，避免外部接口限流。特征消融：

```bash
# 只追加换手率组
go run ./cmd/turnover-study -data-dir /path/to/data -through 2026-10-26 -years 5 -feature-set turnover -offline

# 成交额三组消融
go run ./cmd/turnover-study -data-dir /path/to/data -through 2026-10-26 -years 5 -feature-set amount -offline
go run ./cmd/turnover-study -data-dir /path/to/data -through 2026-10-26 -years 5 -feature-set amount-level -offline
go run ./cmd/turnover-study -data-dir /path/to/data -through 2026-10-26 -years 5 -feature-set amount-dynamics -offline

# 成交额加市值控制
go run ./cmd/turnover-study -data-dir /path/to/data -through 2026-10-26 -years 5 -feature-set amount-size -offline
```

稳健性检查只建议有限组合：

```bash
# Top10
go run ./cmd/turnover-study -data-dir /path/to/data -through 2026-10-26 -years 5 -feature-set amount -top 10 -offline

# 3 日持有
go run ./cmd/turnover-study -data-dir /path/to/data -through 2026-10-26 -years 5 -feature-set amount -horizon 3 -offline

# 安慰剂：置换当日流动性特征块
go run ./cmd/turnover-study -data-dir /path/to/data -through 2026-10-26 -years 5 -feature-set amount -placebo-seed 1 -offline

# 预算敏感性
go run ./cmd/turnover-study -data-dir /path/to/data -through 2026-10-26 -years 5 -feature-set amount -budget 50000 -offline

# 单年分段：数据缓存仍覆盖完整五年，只用 -from/-through 截取信号区间
go run ./cmd/turnover-study -data-dir /path/to/data -through 2026-10-26 -years 5 -feature-set amount -from 2025-01-01 -through 2025-12-31 -offline
```

默认报告写入 `.scratch/turnover-study/report.json`；默认复权缓存为 `qfq-bars.json`，指标缓存为 `metrics.json`。`-from` 缺省时会保留 65 个交易日特征预热；`-min-train-days` 默认 40；`-retrain-every` 默认 5。分段运行只截取信号和评估日期，训练仍使用缓存中更早的历史。

## 2026-10-26 五年窗口复验与特征消融

本次使用 193 只股票、226,514 条搜狐日度指标和完整五年复权 K 线，复权与指标缓存区间均为 `2021-10-26` 至 `2026-10-26`。191 只股票进入特征样本，信号日 1,141 个，评估日 1,095 个，评估区间 `2022-04-11` 至 `2026-10-16`。特征行 212,890 行，已决标签 177,983 行（83.60%），其中正收益标签 83,621 行。

主配置 Top5 / 5 日 / 20,000 元中，基线组与候选组（`full`）平均槽位净收益分别为 `+0.040%` 和 `+0.113%`；已成交交易平均净收益分别为 `+0.057%` 和 `+0.143%`；胜率 `46.56%` 对 `47.59%`，止损率 `21.30%` 对 `17.90%`。按 5 个评估日分组的 219 个 cohort 复利为 `+7.08%` 对 `+25.72%`，最大回撤为 `-21.75%` 对 `-16.92%`。基线与候选分别执行 3,907 笔和 4,318 笔；同一预算下候选改变了可买股票集合，槽位比较不能全部解释为选股能力。

| 五年配置 | 基线平均槽位 | 候选平均槽位 | 增量 | 持仓块 bootstrap 95% 区间 | 正向率 |
| --- | ---: | ---: | ---: | --- | ---: |
| Top5 / 5 日 / 20,000 元，`full` | +0.040% | +0.113% | **+0.073pp** | -0.044% ～ +0.195% | 88.1% |

五年整体增量方向为正，但 95% 区间跨 0；与三年窗口相比，增量没有随样本扩大而变得更稳定。单笔最差净亏损仍为 `-27.32%`，跳空和跌停退出没有被 3% 止损约束。

### 特征组消融

保持同一股池、标签、训练切分和成交模拟，只改变候选组追加的特征：

| 消融组 | 追加特征数 | 基线平均槽位 | 候选平均槽位 | 增量 | 持仓块 bootstrap 95% 区间 | 正向率 |
| --- | ---: | ---: | ---: | ---: | --- | ---: |
| `turnover` | 6 | +0.040% | +0.034% | -0.007pp | -0.094% ～ +0.088% | 44.0% |
| `amount` | 3 | +0.040% | +0.131% | **+0.090pp** | +0.003% ～ +0.179% | 97.9% |
| `amount-size` | 4 | +0.040% | +0.119% | +0.079pp | -0.034% ～ +0.188% | 91.7% |
| `amount-level` | 1 | +0.040% | +0.106% | +0.065pp | -0.019% ～ +0.146% | 94.3% |
| `amount-dynamics` | 2 | +0.040% | +0.039% | -0.001pp | -0.079% ～ +0.079% | 48.8% |

只有成交额三特征组的五年全样本区间勉强不跨 0，下界仅 `+0.003%`；加入市值控制后区间立即跨 0，单独保留成交额水平或成交额变化也都不显著。换手率组几乎为零。由于同时比较了多个特征组，单个接近 0 的区间不能单独作为稳定 alpha 证据。

## 2026-10-26 三年窗口结果（前一阶段）

本次使用 193 只股票、137,036 条搜狐日度指标和完整三年复权 K 线，复权与指标缓存区间均为 `2023-10-26` 至 `2026-10-26`。191 只股票进入特征样本，信号日 655 个，评估日 609 个，评估区间 `2024-04-11` 至 `2026-10-16`。特征行 123,381 行，已决标签 101,033 行（81.89%），其中正收益标签 49,462 行。

主配置 Top5 / 5 日 / 20,000 元中，基线组与候选组平均槽位净收益分别为 `+0.005%` 和 `+0.055%`；已成交交易平均净收益分别为 `+0.007%` 和 `+0.071%`；胜率 `46.62%` 对 `48.03%`，止损率 `15.89%` 对 `13.79%`。按 5 个评估日分组的 122 个 cohort 复利为 `-0.42%` 对 `+5.60%`，最大回撤为 `-10.73%` 对 `-8.86%`。

| 三年配置 | 基线平均槽位 | 候选平均槽位 | 增量 | 持仓块 bootstrap 95% 区间 | 正向率 |
| --- | ---: | ---: | ---: | --- | ---: |
| Top5 / 5 日 / 20,000 元 | +0.005% | +0.055% | **+0.050pp** | -0.111% ～ +0.212% | 70.7% |
| Top10 / 5 日 / 20,000 元 | +0.012% | +0.052% | +0.040pp | -0.079% ～ +0.154% | 74.9% |
| Top5 / 3 日 / 20,000 元 | -0.010% | +0.056% | +0.067pp | -0.066% ～ +0.197% | 82.7% |
| Top5 / 5 日 / 50,000 元 | +0.058% | +0.066% | +0.008pp | -0.145% ～ +0.166% | 52.8% |
| Top5 / 5 日 / 20,000 元，安慰剂 seed 1 | +0.005% | -0.053% | -0.058pp | -0.174% ～ +0.056% | 17.1% |

三年整体增量方向为正，但仍接近零且所有 bootstrap 区间都跨 0；提高预算到 50,000 元后增量进一步消失。安慰剂组没有出现正增量，说明结果不是单纯由增加特征容量造成，但真实特征组也没有形成足够稳定的收益优势。

### 分段稳定性

在同一个三年缓存上截取信号区间，训练仍使用此前已成熟的数据：

| 信号区间 | 实际评估区间 | 基线平均槽位 | 候选平均槽位 | 增量 | 持仓块 bootstrap 95% 区间 | 正向率 |
| --- | --- | ---: | ---: | ---: | --- | ---: |
| 2024-01-26 ～ 2024-12-31 | 2024-04-11 ～ 2024-12-23 | -0.045% | +0.020% | +0.065pp | -0.251% ～ +0.409% | 65.8% |
| 2025-01-01 ～ 2025-12-31 | 2025-03-17 ～ 2025-12-23 | +0.119% | +0.086% | -0.032pp | -0.370% ～ +0.284% | 41.5% |
| 2025-10-14 ～ 2026-10-16 | 2025-12-19 ～ 2026-10-08 | -0.237% | +0.162% | +0.399pp | +0.104% ～ +0.689% | 99.7% |

改善明显集中在最近一年；2025 年分段反而为负。因此三年整体结果不是稳定的跨市场状态 alpha，更像是对近期交易环境和候选结构的阶段性适配。

### 与早期一年窗口的关系

前一阶段用 BaoStock 指标和库内一年前复权窗口得到 Top5 / 5 日增量 `+0.512pp`，95% 区间 `+0.215%` 至 `+0.819%`；当时 50,000 元与 100,000 元预算的区间已经跨 0。当前改由新浪复权价和搜狐指标复验后，最近一年分段仍得到 `+0.399pp`、区间 `+0.104%` 至 `+0.689%`，方向相近；但 2024、2025 年分段和三年整体不支持“稳定改善”。早期一年结果只能作为假设来源，不能作为生产接入证据。

最后一次三年重训的标准化系数中，`log_turnover_rate`、`log_amount_ratio_5` 为正，`log_turnover_5_20`、`turnover_z_20`、`amount_z_20`、`log_float_mcap` 为负；符号与早期一年窗口并不完全一致。单次系数只能描述当前拟合方向，不能替代稳定性、因果或交易成本验证。

## 解释与限制

- **五年窗口仍未确认稳定优势。** 全特征组 Top5 / 5 日增量为 `+0.073pp`，区间 `-0.044%` 至 `+0.195%` 跨 0；成交额三特征组虽然得到 `+0.090pp`、区间 `+0.003%` 至 `+0.179%`，但下界几乎贴着 0，且加入市值控制、只保留水平或只保留变化后都跨 0。多组比较下，这个接近零的区间不能单独视为稳定 alpha。
- **换手率本身没有增量。** 单独追加换手率 6 特征时增量为 `-0.007pp`，区间 `-0.094%` 至 `+0.088%`，正向率 `44.0%`；此前三年窗口的正方向并非由换手率贡献。
- **成交额增量集中在早期年份。** 2022 年 `+0.152pp`、2023 年 `+0.118pp`、2024 年 `+0.027pp`、2025 年 `+0.005pp`、最近一年 `+0.019pp`；2023 年起所有年度区间都跨 0。全样本显著性主要由 2022 年贡献，不能外推为当前市场状态下的稳定优势。
- **预算、TopN 和持有期都会改变结论。** 成交额组在 50,000 元预算下为 `+0.066pp`、Top10 为 `+0.035pp`、3 日持有为 `+0.023pp`，区间全部跨 0。候选排序还会改变可买股票集合和成交路径（五年主配置执行 4,318 笔对 3,907 笔），不能把槽位改善全部解释为选股能力。
- **安慰剂没有提供稳定支持。** 三个 seed 的成交额组增量分别为 `-0.007pp`、`+0.020pp`、`-0.078pp`，其中 seed 3 的区间完全为负。真实特征组没有稳定复制正方向，不能据此排除容量或样本偶然性。
- **不是生产第一层模型的精确复现。** 基线是同样的 8 个特征重新拟合的 logistic 代理，生产 `firststage` 是冻结的 `future_three_day_max_high_touch_1pct` artifact；本研究的标签是 3% 目标/3% 止损/5 日持有。结论只回答“在这套特征和标签下，追加流动性特征是否有增量”，不能直接换算成生产模型的提升。
- **股票池仍有选择偏差。** 五年缓存只覆盖当前 193 只龙头股池，不是历史时点全市场；退市、调仓和曾入选股票没有按当时可见性冻结，早期年份的增量可能包含幸存者偏差和市场风格影响。
- **跳空风险仍是主要拖累。** 五年主配置最差单笔净亏损 `-27.32%`，3% 止损无法约束跳空和跌停退出；基线与候选的止损及止损跳空合计仍是最主要的亏损来源。单独建模跳空、过滤无法买入股票，可能比继续堆叠流动性特征更重要。
- **未接入生产。** 当前没有新增 `market.db` 表、没有把 `turn/amount` 写入生产同步链路、没有升级 `firststage`/`secondstage` 特征版本，也没有生成新的生产 artifact。研究结论不会自动进入推荐或通知。
