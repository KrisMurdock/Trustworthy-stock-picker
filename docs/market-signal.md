# 指数方向信号

该功能从本地 `context.db` 读取上证指数与创业板指历史，按所选截止日重训模型，输出下一交易日收盘方向、上午/下午方向以及周一至周五的历史胜率。它只用于观察和验证，不进入选股排名、风险门槛、飞书主卡或自动交易。

## 数据与目标

### 日线模型

- 输入：`sh000001` 上证指数、`sz399006` 创业板指日线；由默认市场环境同步写入 `<data_dir>/context.db`。
- 截断：只使用 `trade_date <= as_of` 的已完成日线，未来数据不会进入特征或标签。
- 标签：相邻两个可用交易日的收盘价比较；下一日收盘更高为上涨，更低为下跌，持平样本不参与模型训练。
- 目标：在最新已保存交易日收盘后，预测下一交易日收盘方向。目标日期由内置交易日历的 `Next` 计算。

### 上午/下午树模型

- 主输入：`context_minute_30` 中的指数原生 30 分钟线；没有 30 分钟缓存时回退到 `context_minute` 的 5 分钟线。
- 完整 30 分钟交易日必须包含 10:00、10:30、11:00、11:30、13:30、14:00、14:30、15:00 八根；5 分钟回退要求完整 48 根。
- 上午标签：目标交易日 11:30 收盘高于前一交易日 15:00 收盘为上涨。
- 下午标签：目标交易日 15:00 收盘高于当日 11:30 收盘为上涨。
- 特征截断：日线特征只使用目标日前一交易日及更早的数据；前一交易日上午/下午收益和 5 日均值也只使用目标日前的已完成交易日。目标日的日线、收盘价或下午数据不会进入盘前特征。
- 目标日：与日线模型相同，均为下一交易日。

30 分钟和 5 分钟缓存由同一命令补采：

```bash
stock-watcher sync-index-minutes -as-of 2026-10-26 -from 2024-03-01
```

新浪公开接口单次最多返回约 5001 根；30 分钟线通常覆盖最近约 625 个完整交易日，5 分钟线只覆盖最近约 100 个交易日。BaoStock 指数分钟当前对上海指数返回空数据，因此不进入默认路径。

### 韩国指数特征

韩国 KOSPI（`KOSPI`）和 KOSDAQ（`KOSDAQ`）日线由 Naver 日线接口补采：

```bash
stock-watcher sync-korea-context -as-of 2026-10-26 -from 2024-01-01
```

- 韩国市场在北京时间前一日收盘后已经形成当日日线，下一交易日中国盘前可以使用，因此只取“严格早于中国目标日”的最后一根韩国日线。
- 特征包括 KOSPI/KOSDAQ 的 1/5/20 日收益、5/20 日已实现波动、振幅和开盘缺口，共 14 个；缺少任一韩国指数时回退为纯境内特征，不会用零值伪装成已启用。
- Naver 分钟接口只保留最近约 4 个交易日，不能回补完整训练区间。`sync-korea-minutes` 只做前向采集并写入 `context_korea_minute`，默认随 `sync`/`run` 的市场环境同步执行；在积累 60～120 个独立交易日前，这些分钟数据不进入预测模型，不能声称使用了韩国同日盘中走势。

### 恒生指数影子特征

恒生指数日线由腾讯接口补采，只保存在 `context_hang_seng` 中，且只作为下午影子模型的特征：

```bash
stock-watcher sync-hang-seng-context -as-of 2026-10-26
```

- 严格只读取目标交易日之前最后一根恒生指数日线；目标日当天或之后的数据不会进入特征。
- 特征为 1/5/20 日收益、20 日已实现波动、振幅、开盘缺口和收盘位置，共 7 个。
- 恒生数据缺失、滞后超过 10 个自然日或样本不足时，影子状态显示 `stale` 或 `insufficient_history`；不会用旧值静默填充。
- 恒生影子只出现在下午会话的 `sessions[].shadow.hang_seng`，不改变正式 `direction`、`up_probability` 或 `high_confidence`。

## 模型

### 日线模型

- 纯 Go、固定迭代次数和固定 L2 惩罚的逻辑回归，模型标识为 `index_direction_logistic_v1`。
- 数值特征：1/5/20/60 日收益、5/20 日已实现波动、相对 MA5/MA20 距离、RSI14。
- 周内特征：目标交易日为周二至周五的哑变量，周一作为基准组。
- 样本外验证：按时间顺序保留最近 40 个有标签样本；此前样本训练模型，输出准确率，并同时计算“训练集多数类”和“同星期历史多数类”两个基线。
- 最终信号：使用截止日前全部可用有标签样本重新训练。

### 上午/下午树模型

- 模型为纯 Go、确定性的 CART 二分类树，模型标识为 `index_session_tree_v3`。
- 上午树最大深度 3，下午树最大深度 2；最小叶样本 8；切分按加权 Gini 不纯度，平局按较小特征索引和较小阈值确定。
- 叶概率使用 Beta(2,2) 先验平滑，避免小样本纯叶输出 0% 或 100%。
- 特征：日线 1/5/20/60 日收益、5/20 日波动、MA5/MA20 距离、RSI14、目标星期哑变量，加上前一交易日上午/下午收益和 5 日均值；韩国缓存可用时追加 14 个韩国日线特征。
- 验证：
  - 按时间顺序保留最近 20 个样本作为留出验证。
  - 从第 40 个样本开始做扩张窗口滚动验证，每次向后滚动 10 个样本。
  - 高置信度子集定义为校准概率 `>= 65%` 或 `<= 35%`，且原始树方向和校准方向一致；报告覆盖率、Wilson 95% 区间和可靠性状态，不用单一 20 天留出样本宣称 90%。
  - 概率校准使用扩张窗口 walk-forward 的样本外树叶概率拟合 Platt 逻辑映射；校准样本少于 30 条时保持原始概率。校准只改善可解释性，不会把无区分度的模型变成高准确率模型。
  - 只有校准样本足够、校准高置信子集不弱于原始高置信子集时，`high_confidence_status=ok`；否则信号不会标记高置信。
- 最终信号：使用截止日前全部可用样本重新训练，预测下一交易日。上午和下午分别训练，互不共享标签。

### 多窗口影子集成

- 正式模型仍为 `index_session_tree_v3`。影子集成固定使用 120、180、240 日和扩张窗口（0），每个窗口至少 30 条训练样本，并把各窗口概率等权平均。
- 从第 120 条样本开始，每 10 条做一次 walk-forward；输出影子概率、预测覆盖率、整体准确率、多数类基线、`>=65%` 强信号子集和分年度验证。分窗口结果也保留，便于识别窗口敏感性。
- 影子结果位于 `sessions[].shadow.multi_window`，只用于研究；不进入正式推荐、高置信门控、飞书、选股排名或自动交易。历史实验显示该集成对窗口选择敏感，创业板上午曾出现退化，因此不能把单一年份或单一时段的高点当作稳定 90% 能力。

## API 与 CLI

```bash
GET /api/market-signal
GET /api/market-signal?as_of=2026-10-26

stock-watcher market-signal
stock-watcher market-signal -as-of 2026-10-26
```

不传 `as_of` 时使用 `context_sync.as_of`。若同步状态晚于最新指数日线，响应状态为 `stale`，信号按最新已保存日线计算并明确标记。

主要字段：

| 字段 | 含义 |
| --- | --- |
| `status` | `ok`、`stale`、`partial` 或 `insufficient_history` |
| `data_through` | 实际使用的最后一条指数日线日期 |
| `target_date` | 该信号的下一交易日 |
| `up_probability` | 日线模型输出的上涨概率 |
| `strength` | 概率相对 50% 的距离，仅用于显示强弱 |
| `training` | 最终模型的样本数、起止日期、上涨/下跌标签数 |
| `validation` | 日线留出验证的模型、多数类和同星期基线准确率 |
| `weekdays` | 周一至周五的日线样本数、上涨/下跌/平盘数、上涨胜率、平均日收益和 Wilson 95% 区间 |
| `session_model` | 树模型标识、特征顺序、深度、置信阈值、90% 目标口径和 `korea_features` |
| `sessions` | 上午/下午各一条信号，包含方向、原始概率、校准概率、高置信标记、训练信息和验证指标 |
| `sessions[].up_probability` / `calibrated_up_probability` | 树叶原始方向概率与 walk-forward Platt 校准概率；方向仍由原始树输出决定 |
| `sessions[].validation.high_confidence_status` | `ok`、`insufficient_samples`、`below_raw`、`calibration_insufficient` 或 `no_samples`；只有 `ok` 才允许标记高置信 |
| `sessions[].validation` | 留出准确率、多数类基线、同星期基线、滚动验证、样本外校准 Brier/ECE、高置信覆盖率/准确率/Wilson 区间和可靠性状态 |
| `sessions[].shadow.multi_window` | 120/180/240/扩张窗口影子集成；包含当前概率、覆盖率、准确率、多数基线、强信号子集、分窗口和分年度结果 |
| `sessions[].shadow.hang_seng` | 仅下午存在的恒生指数影子；包含状态、特征顺序、概率、覆盖率和验证指标，不参与正式信号 |

以下结果基于 2026-10-26 本地数据。30 分钟缓存覆盖 2024-03-28 至 2026-10-26 的 622 个完整交易日；去掉日线前置窗口和 5 日会话回看后，最终训练样本 584 个（2024-05-29 至 2026-10-26）。韩国日线覆盖 2024-01-02 至 2026-10-26。

韩国日线特征对创业板上午的滚动准确率仍有约 9 个百分点的提升；对上证上午只有约 2 个百分点提升，对下午没有稳定增益。校准器使用 544 条滚动预测拟合，Brier/ECE 只用后续 514 条样本外预测评估；校准没有稳定提高整体方向准确率，例如创业板上午从 57.0% 降到 53.3%，因此只用于置信门控，不改写方向。所有时段都没有达到 90%；唯一通过可靠性门控的创业板下午校准高置信子集为 60.5%，覆盖 14.0%，Wilson 95% 约 49.3%～70.8%。此前 93 天 5 分钟样本的 62%～68% 结果属于小样本波动，不应再用作稳定性能结论。

### 11:30 下午特征实验

为验证“预测当天下午时使用当天上午特征”，额外测试了上午收益、振幅、收盘位置、量比、VWAP 偏离、开盘缺口和上午最后 30 分钟收益，并分别与日线、昨日会话和韩国日线特征组合。结果显示：

- 创业板下午最佳整体准确率约 56.6%，仅比滚动多数基线 55.1% 高 1.5 个百分点；高置信子集约 59%～61%。
- 上证下午最佳整体准确率约 53.5%，仍低于可接受门槛。
- 当日早盘特征没有稳定超过原始盘前模型，因此没有接入生产；当前 `sessions[].mode` 仍为 `pre_open`，11:30 模型只作为离线研究路径保留。
- 如果未来改成 11:30 发布下午信号，需要新增明确的决策时点和数据截断契约，不能把目标日早盘数据混入当前盘前信号。

### 上午/下午周内胜率

| 指数 | 时段 | 周一 | 周二 | 周三 | 周四 | 周五 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 上证指数 | 上午 | 61.7% | 48.6% | 59.1% | 53.2% | 52.3% |
| 上证指数 | 下午 | 64.5% | 60.6% | 50.0% | 48.6% | 36.4% |
| 创业板指 | 上午 | 45.8% | 45.0% | 59.1% | 50.5% | 50.5% |
| 创业板指 | 下午 | 56.1% | 51.4% | 47.3% | 37.8% | 31.8% |

这是目标时段的实际上涨率，不是模型准确率。上证下午“周一/周二偏强、周四/周五偏弱”的形态较明显，创业板下午尾段也偏弱；但上午没有同样规律，且滚动星期多数基线只有约 52.9%～56.4%，不足以单独支撑 90%。每格约 107～111 个样本，仍不能据此断言稳定的周内季节效应。

### 影子模型与后续实验

本轮在相同的 544 个滚动预测上逐项增加信息源，不改变正式模型的其他参数。多窗口集成和恒生下午特征已以影子字段接入网页与 API；韩国分钟缓存只做前向积累，尚未进入预测。以下结果用于解释影子指标，不构成正式推荐能力：

| 路线 | 观测结果 | 判断 |
| --- | --- | --- |
| 上一交易日恒生指数日线 | 上证下午 51.3%→55.0%，创业板下午 55.0%→56.6%；上午没有提升，创业板上午反而降至 54.2% | 已接入下午影子；腾讯接口仅提供约 640 个日线，不能替代完整历史 |
| 120/180/240 日与扩张窗口集成 | 在要求 240 条训练样本的共同 304 天中，上证上午 53.6%→55.9%，上证下午 53.6%→58.9%，创业板上午 54.0%→51.0%，创业板下午 52.6%→56.6%；改用 90/180/360 日窗口后结果明显回落 | 已接入影子展示；窗口敏感，不能直接接管正式推荐 |
| 行业/概念板块横截面广度 | 上证上午 52.4%→55.7%，2025 年 55.6%→60.1%、2026 年 47.9%→51.5%；下午和创业板没有稳定增益 | 可作为上证上午的候选特征，但高置信准确率仍只有约 53% |
| 其余境内核心指数 | 完整加入后多数时段低于基线，仅少数组合有一到两个百分点变化 | 直接拼接噪声较大，暂不优先 |
| 前一交易日 30 分钟路径形态 | 单独加入后，四个时段没有稳定超过 v3；部分组合甚至下降三个百分点以上 | 路径形态不是当前的主要瓶颈 |
| 11:30 当日早盘特征 | 继续扩展早盘收益、振幅、VWAP 偏离、量比和最后 30 分钟收益后，下午仍没有稳定增益 | 预测下午前仍需保留盘前信号；若改 11:30 发布，必须另建决策时点契约 |
| 韩国盘中分钟线 | Naver 分钟接口的本次历史查询只能取得最近 4 个交易日，无法回补两年训练区间 | 只能从今天起持续采集，至少积累 60～120 个独立交易日后再验证“韩国上午→中国下午” |

优先顺序建议：

1. 先用固定窗口集合把多窗口树集成做成影子模型，记录每日预测但不改写正式推荐；同时评估逐日覆盖率、Wilson 区间和分年度漂移。
2. 为下午模型增加“上一交易日恒生指数”特征并建立独立缓存与回退；先作为研究开关，不替换当前模型。
3. 新增韩国分钟线前向采集。历史回补不可行时，不要用最近几天或目标日数据填充训练集。
4. 不优先继续拼接境内核心指数、板块广度或早盘形态；这些路线的增量不稳定，容易在不同年份反转。

上述实验最好的高置信子集仍约 57%～68%，没有任何路线接近 90%。因此下一阶段应把“90% 全样本方向准确率”改为“预先定义、覆盖率受限且带 Wilson 下界的高置信子集”，并把新增数据的前向样本外验证作为上线门槛。

## 90% 目标口径

下一交易日方向的全样本 90% 准确率在当前数据上不可信，也不应通过以下方式制造：

- 使用目标日收盘价、目标日日线特征或目标日下午数据训练盘前信号；
- 用韩国目标日的数据填充“前一交易日”特征；
- 只保留回测中有利的日期或事后挑选阈值；
- 用 20 天留出样本的偶然高准确率替代滚动样本外验证；
- 把高置信度子集的点估计当作全样本成功率。

当前实现只报告可复核的留出、滚动、校准和高置信度子集指标。校准改善的是概率质量和置信门控，不会把弱模型变成 90% 模型。若后续要接近 90%，至少需要更长的中国指数分钟历史、更多独立前向样本，以及韩国历史盘中数据或成交结构等新信息源，并在预注册的样本外区间验证。即使达到 90% 的高置信度子集，也必须同时报告覆盖率、Wilson 区间、校准状态和分年度结果。

## 限制

- 本地指数日线从 2024-02-27 开始，约 645 个交易日；30 分钟缓存约 622 个完整交易日，5 分钟缓存约 100 个完整交易日。
- 韩国数据只有日线；Naver 历史分钟接口不可用，不能回补韩国盘中走势。
- 模型只预测方向，不预测幅度、成交路径、最高/最低价或收益风险比。
- 指数方向信号不改写个股推荐、机会分、结构门控或仓位计算。
- 信号不发送飞书消息；需要推送时必须先完成独立的前向验证和投递契约设计。
- `context.db` 同步失败、指数日线滞后、30 分钟缓存未对齐或韩国缓存缺失时，响应会标记 `stale` 或 `insufficient_history`；先修复同步，不要用陈旧目标日做交易判断。
