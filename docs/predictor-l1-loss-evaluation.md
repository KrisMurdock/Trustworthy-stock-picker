# 5 分钟预测 close L1 损失评估（2026-10-22）

本轮验证训练损失与主指标是否对齐。结论先行：**只对 close 使用 L1 损失可以小幅但稳定地降低 close MAE，并改善方向准确率；high/low 继续使用 L2，包络覆盖率不变。全目标 L1 虽然点误差更低，但会显著压缩 high/low 包络，否决。**

## 1. 范围与口径

- 验证区间：2026-09-21 至 2026-10-20，16 个交易日。
- 股票池：149 只 `config-diagnostic` 股票；每个验证日 6,854 条样本，共 109,664 条。
- 模型：FeatureVersion 1 的 B0 expanding 基线；训练窗口限制为最近 60 个交易日，约 40.9 万条训练样本。
- 指标：close/high/low 为日等权 MAE，单位 bps；方向只统计实际收益非零样本，预测为 0 计错；bootstrap 按验证日重采样 10,000 次。
- 该口径使用当前股池，存在幸存者偏差，不是正式 point-in-time 样本外验收；60 日训练窗口也与生产全历史重训不同。

## 2. 基线（L2）

| 指标 | 结果 |
| --- | ---: |
| close MAE | 25.9211 bps |
| high MAE | 18.0956 bps |
| low MAE | 15.2764 bps |
| close 方向准确率 | 52.34% |
| 多数类准确率 | 54.46% |
| high/low 包络覆盖率 | 22.67% |
| 预测区间平均宽度 | 46.77 bps |

## 3. 仅 close 使用 L1

保持 high/low 的 L2 训练不变，只把 close 的训练损失改为 L1。close 的初始值和叶值使用残差中位数，high/low 仍使用均值与平方误差分裂。

| 指标 | L2 | close L1 | 变化 | 95% CI | 改善天数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| close MAE | 25.9211 | 25.7643 | -0.1568 bps | [-0.2990, -0.0319] | 12/16 |
| high MAE | 18.0956 | 18.0956 | 0 | — | — |
| low MAE | 15.2764 | 15.2764 | 0 | — | — |
| close 方向 | 52.34% | 54.26% | +1.92 pp | [+0.66, +3.25] | 6/16 |
| 包络覆盖率 | 22.67% | 22.67% | 0 | — | — |
| 区间平均宽度 | 46.77 bps | 46.77 bps | 0 | — | — |

close MAE 的改善幅度不大，但方向一致：16 天中 12 天改善，最差单日回退约 0.21 bps，最好单日改善约 0.80 bps。方向准确率仍略低于多数类 `54.46%`，不能表述为稳定跑赢多数类；它的价值是相对 L2 的方向信号更强，同时不牺牲 high/low 包络。

4 日 `-close-loss l1` 实际代码路径复核：close MAE 29.6525 vs L2 29.8574（-0.205 bps），high/low 基本不变，且 close 预测与离线“L1 close + L2 high/low”组合逐样本一致。

## 4. 全目标 L1

| 指标 | L2 | 全 L1 | 变化 | 95% CI | 改善天数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| close MAE | 25.9211 | 25.7643 | -0.1568 bps | [-0.2990, -0.0319] | 12/16 |
| high MAE | 18.0956 | 17.4684 | -0.6272 bps | [-0.8679, -0.3733] | 13/16 |
| low MAE | 15.2764 | 15.0594 | -0.2170 bps | [-0.3571, -0.0846] | 13/16 |
| 包络覆盖率 | 22.67% | 12.19% | -10.48 pp | — | — |
| 区间平均宽度 | 46.77 bps | 37.82 bps | -8.95 bps | — | — |
| 内部矛盾样本 | 30 | 200 | +170 | — | — |

全 L1 的三目标 MAE 都改善了，但 high/low 包络明显收窄，覆盖率从 22.67% 降到 12.19%，并出现 200 条 close 落在 high/low 之外的内部矛盾。把 high/low 同步放大 1.2 倍可以把覆盖率恢复到 21.60%，但 low MAE 变为 15.335 bps，已经差于 L2 的 15.276 bps，平均收益也基本消失。因此**全 L1 不进入生产**。

## 5. 训练窗口与 close 校准对照

同一 4 日验证窗口上比较训练窗口（L2）：

| 训练窗口 | close MAE | high MAE | low MAE |
| ---: | ---: | ---: | ---: |
| 20 日 | 30.2080 | 21.1628 | 17.0643 |
| 60 日 | 29.8574 | 20.9157 | 16.9589 |
| 120 日 | 29.8313 | 20.9089 | 17.0067 |

20 日窗口三目标都变差；120 日相对 60 日基本持平（close -0.026 bps，high -0.007 bps，low +0.048 bps）。训练窗口不是本轮的稳定增益来源。

close 幅度校准同样没有通过留出检验：

- 固定缩放 0.50：16 日全样本 MAE 改善 -0.0624 bps，但按前后 8 日拆分后，后半段为 -0.0789 bps，95% CI [-0.2102, +0.0310]，跨 0。
- 每日自适应选择缩放：MAE 改善 -0.0652 bps，95% CI [-0.1556, +0.0254]，跨 0，且每日选择的缩放从 0 到 1 大幅跳动。
- 用 high/low 组合估计 close、close/high/low 偏置修正、按置信度或时段分层，均未在留出段稳定改善。

## 6. 结论与生产变更

- **采用**：`ProductionTrainOptions` 对 close 使用 L1，high/low 保持 L2。生产 artifact 的 `info.loss=l2`、`info.close_loss=l1` 会记录该选择。
- **回退**：`predictor-eval -close-loss l2` 或把 `ProductionTrainOptions` 中的 `CloseLoss` 改回空值即可恢复原行为。
- **保留研究**：`predictor-eval -loss l1` 仍可做全目标 L1 对照；全目标 L1 不作为生产默认。
- 旧 artifact 没有 `loss`/`close_loss` 字段时按 L2 处理，推理行为不变。artifact 解码是严格模式，新 artifact 不能由旧二进制读取；回滚需要同时恢复升级前的旧 artifact 或完整数据备份。

## 7. 限制与后续

- 16 个验证日、`config-diagnostic` 股池、60 日训练窗口，均不是正式 point-in-time 或生产全历史重训验证。
- close MAE 的绝对改善约 0.16 bps，方向仍低于多数类；不能据此表述为“预测能力已显著提升”。
- L1 叶值中位数计算比 L2 慢，生产训练时间会略有增加；需要在真实全量训练上记录 `train_duration_ms`，超过可接受窗口时回退。
- 下一轮优先在正式 point-in-time 股池和更长样本外窗口上复验 close L1，并比较全历史训练与 60 日诊断窗口的差异；再考虑分位数/区间模型，而不是继续堆点回归特征。

## 8. 复现

```bash
STOCK_WATCHER_DATA_DIR=<data_dir> \
STOCK_WATCHER_REQUIRE_CIFS=true \
STOCK_WATCHER_FEISHU_ENABLED=false \
go run ./cmd/stock-watcher predictor-eval \
  -as-of 2026-10-20 \
  -windows 60 \
  -validation-days 16 \
  -loss l2 \
  -close-loss l1
```

`-loss l2 -close-loss l1` 复现生产候选；`-loss l1` 复现全目标 L1 否决实验。评估只读取本地已保存行情，不写模型、预测库或飞书。
